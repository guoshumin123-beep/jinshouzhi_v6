# orders.$contract_code (订阅订单数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19580a58ac9

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 当订单发生下单、订单撤单等事件时，推送消息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | string | 是 | 合约代码，支持大小写全部：*（交割和永续）， 永续:“BTC-USDT：... ，交割："BTC-USDT-210625"... |
| cid | string | 否 | 表示本次请求id |

**响应参数说明**：假设订单一次成交，且匹配了多个完全成交，则订单频道多次推送的状态都是“filled-完全成交“，但成交量可能小于下单量。
假设IOC订单部分成交剩余撤单，则订单频道状态是“partially_canceled-部分被撤销“。

## 请求示例
```json
{"op": "sub", "cid": "zTX5sUJscf", "topic": "orders", "contract_code": "*"}
```

## 响应示例
```json
{
  "op": "sub",
  "cid": "zTX5sUJscf",
  "topic": "orders",
  "ts": 1790690173048,
  "err-code": 0,
  "contract_code": "*"
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| op | String | 是 | 操作名称，推送固定值为 notify;--可不可以去掉 |
| topic | String | 是 | 推送的主题orders |
| ts | long | 是 | 服务端应答时间戳 |
| uid | String | 是 | 用户uid |
| data | List<Object> | 否 | 数据详情 |
| > contract_code | String | 是 | 合约代码永续："BTC-USDT"... ，交割："BTC-USDT-210625".. |
| > side | String | 是 | 买卖方向buy:买 "sell":卖 |
| > position_side | String | 是 | 仓位方向"long":多 "short":空 “both”:单向持仓 |
| > type | String | 是 | 订单类型；枚举"market": 市价，"limit":限价, "post_only":只挂单 |
| > price_match | String | 是 | 价格匹配 |
| > order_id | String | 是 | 订单id |
| > client_order_id | String | 是 | 用户自定义订单ID |
| >margin_mode | String | 是 | 保证金模式枚举 cross |
| > price | String | 是 | 委托价格 |
| >volume | String | 是 | 委托数量<br>该值会随着改单成功而发生变化 |
| > lever_rate | Long | 是 | 杠杆等级 |
| > state | string | 是 | 订单状态new, partially_filled, , partially_canceled, filled ,canceled, |
| > trade_turnover | String | 是 | 累计成交金额 |
| > order_source | String | 是 | 订单来源（system:系统、web:用户网页、api:用户API、m:用户M站、risk:风控系统、settlement:交割结算、ios：ios客户端、android：安卓客户端、windows：windows客户端、mac：mac客户端、trigger：计划委托触发、tpsl:止盈止损触发、ADL: adl订单） |
| > cancel_reason | String | 是 | 撤单原因<br>如果没有发生过撤单，该字段返回“”"Limit order cancelation by the client":"用户主动撤销普通限价订单","Order cancelation by system":"系统撤单","Market order circuit-breaker":"市价单熔断","Bankruptcy price of market order":"市价单破产价","Order cancelation due to no matching orders":"没有对手盘导致撤单"," Self trading prevention":"防自成交撤单","Number of maker orders matched with your taker orders exceeding limit":"成交笔数超过最大限制","Order cancelation due to API timeout":"API超时撤单","Cancel‑on‑trigger for RPI Order", "撮合:RPI订单触价即撤" |
| > reduce_only | Boolean | 是 | 只减仓 |
| > time_in_force | String | 是 | 枚举fok, ioc, gtc，rpi,非必填，默认是gtc |
| > trade_avg_price | String | 是 | 成交均价 |
| > trade_volume | String | 是 | 累计成交数量 |
| > cancel_volume | String | 否 | 撤单数量（张）。订单未发生过撤单时返回 "0"。订单终态：state 为 filled、canceled 或 partially_canceled 时，订单已到达终态。<br>推送终态：trade_volume + cancel_volume == volume 时，推送已到达终态。 |
| > fee_currency | String | 是 | 手续费币种，多个则使用","分隔 |
| > fee | String | 是 | 总手续费(U) |
| > tp_trigger_price | String | 是 | 止盈触发价格 |
| > tp_order_price | String | 是 | 止盈委托价格（最优N档委托类型时无需填写价格） |
| > tp_type | String | 是 | 止盈委托类型,不填默认为market: 市价，maket: 限价：limit ，最优5档： optimal_5，最优10档：optimal_10，最优20档：optimal_20 |
| > tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价"last":最新价，"mark"：标记价格 |
| > sl_trigger_price | String | 是 | 止损触发价格 |
| > sl_order_price | String | 是 | 止损委托价格（最优N档委托类型时无需填写价格） |
| > sl_type | String | 是 | 止损委托类型,不填默认为 市价，maket: 限价：limit ，最优5档： optimal_5，最优10档：optimal_10，最优20档：optimal_20 |
| > sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价"last":最新价，"mark"：标记价格 |
| > price_protect | boolean | 否 | 价差保护，默认为false。仅当设置止盈/止损需要该参数。false 或者 true |
| > profit | String | 是 | 平仓盈亏 |
| > contract_type | String | 是 | 业务类型swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季） |
| > created_time | String | 是 | 订单创建时间, UTC时间戳(MS) |
| > updated_time | String | 是 | 订单更新时间, UTC时间戳(MS) |
| > self_match_prevent | String | 是 | 防自成交allow: 允许自成交 cancel_taker ：撤销taker单 cancel_maker：撤销maker单 cancel_both：撤销全部订单 |
| > amend_origin_volume | String | 是 | 改单前的原始委托数量<br><br>改单成功的情况下，改字段有值。其他情况返回“”。 |
| > amend_source | String | 是 | 订单修改原因<br><br>如果没有发生过改单，该字段返回“”1: 用户下单，被只减仓修改，改单成功<br>2: 用户挂单，被只减仓修改，改单成功 |
| > amend_result | String | 是 | 修改订单的结果<br><br>如果没有发生过改单，该字段返回“”-1: 失败<br><br>0: 成功 |
