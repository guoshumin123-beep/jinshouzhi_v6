# match_orders.$contract_code (订阅撮合后的订单数据 )

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19710f62bf5

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 当订单发生下单、订单撤单、成交等事件时，从撮合里引擎面推送消息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | string | 是 | 合约代码，支持大小写全部：*（交割和永续）， 永续:“BTC-USDT：... ，交割："BTC-USDT-210625"... |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{
  "op": "sub",
  "cid": "bf50e5c7ca",
  "topic": "match_orders",
  "contract_code": "*"
}
```

## 响应示例
```json
{
  "op": "sub",
  "cid": "bf50e5c7ca",
  "topic": "match_orders",
  "ts": 1790690785426,
  "err-code": 0,
  "contract_code": "*"
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| op | String | 是 | 操作名称，推送固定值为 notify;--可不可以去掉 |
| topic | String | 是 | 推送的主题 orders |
| ts | long | 是 | 服务端应答时间戳 |
| uid | String | 是 | 用户uid |
| <data> |  | 否 |  |
| contract_code | String | 是 | 合约代码永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| side | String | 是 | 买卖方向buy:买 "sell":卖 |
| position_side | String | 是 | 仓位方向"long":多 "short":空 “both”:单向持仓 |
| type | String | 是 | 订单类型；枚举"market": 市价，"limit":限价, "post_only":只挂单 |
| price_match | String | 是 | 价格匹配行情当前没有 |
| order_id | String | 是 | 订单id |
| client_order_id | String | 是 | 用户自定义订单ID |
| trade_id | String | 是 | 成交id |
| margin_mode | String | 是 | 保证金模式枚举 cross |
| price | String | 是 | 委托价格 |
| volume | String | 是 | 委托数量<br>该值会随着改单成功而发生变化 |
| lever_rate | String | 是 | 废弃参数 |
| state | int | 是 | 订单状态new, partially_filled, partially_canceled, filled ,canceled, |
| order_source | String | 是 | 订单来源system:系统<br>web:用户网页<br>api:用户API<br>m:用户M站<br>risk:风控系统<br>settlement:交割结算<br>ios：ios客户端<br>android：安卓客户端<br>windows：windows客户端<br>mac：mac客户端<br>trigger：计划委托触发<br>tpsl:止盈止损触发 |
| time_in_force | String | 是 | 枚举fok, ioc, gtc，rpi,非必填，默认是gtc |
| reduce_only	 | Boolean | 是 | 只减仓 |
| trade_price | String | 是 | 成交均价 |
| trade_volume | String | 是 | 成交数量 |
| total_trade_volume | String | 是 | 累计成交数量 |
| cancel_reason | String | 否 | 撤单原因"Limit order cancelation by the client":"用户主动撤销普通限价订单","Order cancelation by system":"系统撤单","Market order circuit-breaker":"市价单熔断","Bankruptcy price of market order":"市价单破产价","Order cancelation due to no matching orders":"没有对手盘导致撤单"," Self trading prevention":"防自成交撤单","Number of maker orders matched with your taker orders exceeding limit":"成交笔数超过最大限制","Order cancelation due to API timeout":"API超时撤单","Cancel‑on‑trigger for RPI Order", "撮合:RPI订单触价即撤" |
| created_time | String | 是 | 订单创建时间, UTC时间戳(MS) |
| match_time | String | 是 | 撮合更新时间, UTC时间戳(MS)撮合时间 |
| self_match_prevent | String | 是 | 防自成交allow: 允许自成交 cancel_taker ：撤销taker单 cancel_maker：撤销maker单 cancel_both：撤销全部订单 |
| id | String | 是 | 记录ID |
| role | String | 是 | 成交角色 taker，maker |
| amend_origin_volume | String | 是 | 改单前的原始委托数量。<br><br>对已有挂单发生改单的且改单成功，该字段有值。<br><br>下单时发生止减仓改单的场景，该字段返回“”。<br><br>其他情况返回“”。 |
| amend_source | String | 是 | 订单修改的来源<br><br>如果没有发生过改单，该字段返回“”1: 用户下单，被只减仓修改，改单成功<br>2: 用户挂单，被只减仓修改，改单成功 |
| amend_result | String | 是 | 修改订单的结果<br><br>如果没有发生过改单，该字段返回“”-1: 失败<br><br>0: 成功 |
| in_time | String | 否 | 在下单时表示新建订单进入撮合系统的时间,在撤销订单时表示撤单请求进入撮合系统的时间，UTC时间戳(MS) |
| cancel_volume | String | 是 | 撤单数量（张）。订单未发生过撤单时返回 "0"。 |
| <data> |  | 否 |  |
