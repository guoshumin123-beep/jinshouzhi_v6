# trade.$contract_code (订阅成交变动数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19582b9e8db

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 发生成交事件时，推送如下消息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | string | 是 | 合约代码，支持大小写全部：*（交割和永续）， 永续:“BTC-USDT：... ，交割："BTC-USDT-210625"... |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{"op": "sub", "cid": "ovILlciUtO", "topic": "trade", "contract_code": "*"}
```

## 响应示例
```json
{
  "op": "sub",
  "cid": "ovILlciUtO",
  "topic": "trade",
  "ts": 1790690366966,
  "err-code": 0,
  "contract_code": "*"
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| op | String | 是 | 操作名称，推送固定值为 notify;--可不可以去掉 |
| topic | String | 是 | 推送的主题trade |
| ts | long | 是 | 服务端应答时间戳 |
| uid | String | 是 | 用户uid |
| <data> |  | 否 |  |
| contract_code | String | 是 | 交易对。常用形式为“基础货币”+“报价货币” |
| order_id | String | 是 | 订单ID |
| client_order_id | String | 是 | 用户自定义订单ID |
| id | String | 是 | 成交id |
| direction | String | 是 | 交易方向buy表示买，sell表示卖。 |
| position_side | String | 是 | 仓位方向"long":多，"short":空，“both”:单向持仓。 |
| role | String | 是 | 成交角色maker, taker |
| trade_price | String | 是 | 成交价格 |
| trade_volume | String | 是 | 成交量（张） |
| trade_turnover | String | 是 | 成交金额（成交数量 * 合约面值 * 成交价格） |
| created_time | String | 是 | 创建时间 |
| updated_time | String | 是 | 更新时间，默认为撮合成交时间 |
| contract_type | String | 是 | 合约类型swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季 |
| <data> |  | 否 |  |
