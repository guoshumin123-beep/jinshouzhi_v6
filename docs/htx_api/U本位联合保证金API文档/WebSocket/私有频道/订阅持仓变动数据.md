# positions.$contract_code (订阅持仓变动数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19582def41f

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 当持仓信息发生变更时，例如形成仓位、加仓、平仓、逐仓增加/减少保证金等事件时,推送如下信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | string | 是 | 合约代码，支持大小写全部：*（交割和永续）， 永续:“BTC-USDT：... ，交割："BTC-USDT-210625"... |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{"op": "sub", "cid": "NuAWMqWKSI", "topic": "positions", "contract_code": "DOGE-USDT"}
```

## 响应示例
```json
{"op": "sub", "cid": "NuAWMqWKSI", "topic": "positions", "ts": 1734683308615, "err-code": 0, "contract_code": "DOGE-USDT"}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| op | string | 是 | 操作名称，推送固定值为 notify;--可不可以去掉 |
| topic | string | 是 | 推送的主题<br>例如： positions |
| contract_code | string | 是 | 订阅的contract_code<br><br>* 或者 BTC-USDT 或者 BTC-USDT-240909 |
| ts | long | 是 | 服务端应答时间戳 |
| event | string | 是 | 持仓变化通知相关事件说明<br><br>事件类型 snapshot：首推快照 create_order: 订单下单 cancel_order: 订单撤单 delivered：交割 transferred：划转 filled：成交 liquidation：强平 adl：ADL自动减仓 funding_fee：资金费 set_leverage：设置杠杆 price_update ：价格更新 （api 用户不要） |
| uid | string | 是 | 用户uid |
| <data> |  | 否 |  |
| contract_code | string | 是 | 合约代码 |
| position_side | string | 是 | 仓位方向<br><br>持仓方向 买卖模式下默认值both， 开平仓模式下： long：多 ，short：空 |
| direction | string | 是 | 订单方向<br>"buy":买， "sell":卖 |
| margin_mode | string | 是 | 保证金模式<br>cross：全仓 |
| open_avg_price | string | 是 | 开仓均价 |
| volume | string | 是 | 持仓量（张） |
| available | string | 是 | 可平仓数量（张） |
| fee | string | 是 | 手续费<br>首次推送返回累计的开仓手续费<br>后续增量推送返回的是单次成交手续费 |
| lever_rate | Long | 是 | 杠杠倍数 |
| adl_risk_percent | int | 是 | 自动减仓指示<br><br>(1、2、3、4、5)，1档风险最低，5档风险最高 |
| liquidation_price | string | 是 | 预估强平价 |
| initial_margin | string | 是 | 初始保证金，仅适用于全仓 |
| maintenance_margin | string | 是 | 维持保证金 |
| margin | string | 是 | 为全仓时代表初始保证金，为逐仓时代表仓位保证金 |
| profit_unreal | string | 是 | 未实现盈亏 |
| profit | string | 是 | 已实现盈亏 |
| profit_rate | string | 是 | 未实现收益率 |
| margin_rate | string | 是 | 保证金率 |
| state | string | 是 | 仓位状态<br><br>normal, liq, adl |
| funding_fee | string | 是 | 累计资金费用 |
| last_price | string | 是 | 最新价格 |
| mark_price | string | 是 | 标记价格 |
| contract_type | string | 是 | 业务类型<br><br>swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季） |
| created_time | string | 是 | 创建时间 |
| updated_time | string | 是 | 更新时间 |
| version | int | 是 | 版本号 |
| total_trade_fee | string | 是 | 累计手续费 |
| break_even_price | string | 是 | 盈亏平衡价 |
| <data> |  | 否 |  |
