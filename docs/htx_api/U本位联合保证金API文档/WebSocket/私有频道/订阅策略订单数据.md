# algo_orders.$contract_code (订阅策略订单数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b981e8c47

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 当策略委托订单下单、被触发，或者被撤单的时候，推送如下信息给用户. |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码，支持大小写全部：*（交割和永续）， 永续:“BTC-USDT：... ，交割："BTC-USDT-210625"... |

## 请求示例
```json
{
  "op": "sub",
  "topic": "algo_orders",
  "contract_code": "*",
  "cid": "1FeLkV9a1C"
}
```

## 响应示例
```json
{
  "op": "sub",
  "cid": "1FeLkV9a1C",
  "topic": "algo_orders",
  "ts": 1767600617457,
  "err-code": 0,
  "contract_code": "*"
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| algo_id | String | 是 | 策略委托单ID |
| algo_client_order_id | String | 是 | 客户自定义策略订单ID |
| contract_code | String | 是 | 交易对名称 |
| volume | String | 否 | 委托张数 |
| type | String | 是 | 订单类型<br><br>tp：止盈<br><br>sl: 止损<br><br>tpsl: 止盈止损<br>trigger：计划委托<br><br>trailing_stop：跟踪委托 |
| state | String | 是 | 状态<br><br>active：等待触发<br><br>effective：完全触发<br><br>canceled：完全取消<br><br>failed: 失败 |
| position_side | String | 是 | 持仓方向<br><br>"long":多<br><br>"short":空<br><br>“both”:单向持仓 |
| margin_mode | String | 是 | 交易模式 |
| side | String | 是 | 订单方向 |
| tp_trigger_price | String | 否 | 止盈触发价格 |
| tp_order_price | String | 否 | 止盈委托价格（最优N档委托类型时无需填写价格） |
| tp_type | String | 否 | 止盈委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价<br><br>last: 最新价<br><br>index：指数价格<br><br>mark：标记价格 |
| sl_trigger_price | String | 否 | 止损触发价格 |
| sl_order_price | String | 否 | 止损委托价格（最优N档委托类型时无需填写价格） |
| sl_type | String | 否 | 止损委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价<br><br>last: 最新价<br><br>index：指数价格<br><br>mark: 标记价格 |
| price | String | 是 | 计划委托委托价格 |
| price_match | String | 否 | 最优档位<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档 |
| trigger_price | String | 否 | 计划委托触发价格 |
| trigger_price_type | String | 否 | 计划委托触发价格类型<br><br>last: 最新价<br><br>index：指数价格<br><br>mark: 标记价格 |
| active_price | String | 否 | 跟踪委托激活价格。如果不填写激活价格，即下单后就被激活。 |
| order_price_type | String | 否 | 跟踪委托最优档位<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>formula_price：理论价格 |
| callback_rate | String | 否 | 跟踪委托回调幅度的比例，如 "0.05"代表"5%" |
| reduce_only | String | 否 | 只减仓 |
| actual_volume | String | 是 | 实际触发数量 |
| actual_price | String | 是 | 实际触发价格 |
| actual_time | String | 是 | 策略触发时间 |
| relation_order_id | String | 否 | 触发后关联的普通订单id |
| created_time | String | 是 | 订单创建时间, UTC时间戳(MS) |
| updated_time | String | 是 | 订单更新时间, UTC时间戳(MS) |
| order_source | String | 是 | system:系统、<br>web:用户网页、<br>api:用户API、<br>m:用户M站、<br>risk:风控系统、<br>settlement:交割结算、<br>ios：ios客户端、<br>android：安卓客户端、<br>windows：windows客户端、<br>mac：mac客户端、<br>trigger：计划委托触发、<br>tpsl:止盈止损触发、<br>ADL: adl订单 |
