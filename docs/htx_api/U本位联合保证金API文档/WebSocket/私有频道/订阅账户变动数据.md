# account (订阅账户变动数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19583056529

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | WebSocket私有订单成交推送接口(需要API KEY验签)<br>一个UID最多同时建立30个私有订单成交推送WS链接。该用户在一个品种(包含该品种的所有周期的合约)上，仅需要维持一个订单推送WS链接即可。<br>单个链接为50次/秒的请求，单个IP链接为100次/秒的请求。<br>注意: 订单推送WS的限频，跟用户RESTFUL私有接口的限频是分开的，相互不影响。 |
| 接口描述 | 当账户的静态金额发生变化的时刻(冻结、释放保证金、资金费率结算、已实现盈亏等)，推送如下账户相关信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.hbdm.com/ws/v5/notification` |
| 线上环境（aws客户首选） | `wss://api.hbdm.vn/ws/v5/notification` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{"op": "sub", "cid": "CEP7ozFIYa", "topic": "account"}
```

## 响应示例
```json
{
  "op": "sub",
  "cid": "CEP7ozFIYa",
  "topic": "account",
  "ts": 1790689810072,
  "err-code": 0,
  "contract_code": ""
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| op | String | 是 | 操作名称<br>notify |
| topic | String | 是 | 推送的主题<br>account |
| contract_code | String | 是 | 合约代码 |
| ts | long | 是 | 服务端应答时间戳 |
| uid | String | 是 | 用户uid |
| event | String | 是 | 账户变化通知相关事件说明<br><br>snapshot：首推快照 <br>create_order: 订单下单 <br>cancel_order: 订单撤单 <br>delivered：交割 <br>transferred：划转 <br>filled：成交 <br>liquidation：强平 <br>adl：ADL自动减仓 <br>funding_fee：资金费 <br>set_leverage：设置杠杆 <br>price_update ：价格更新(api 用户不要) <br>auto_exchange：自动兑换 |
| verson | Long | 是 | 消息版本号 |
| data | Object | 是 | 推送数据 |
| > state | String | 是 | 账户状态<br>"normal":正常（交易，划转）<br>"liquidating":强平中，不允许交易、划转、收取资金费、 <br>"adl":adl中，不允许交易、收取资金费、划转、<br>"open_limit":风控撤单中，合约交易只允许下减仓单，可以转入，不允许转出 |
| > equity | String | 是 | 账户权益 |
| > initial_margin | String | 是 | 初始保证金 |
| > maintenance_margin | String | 是 | 维持保证金 |
| > maintenance_margin_rate | String | 是 | 维持保证金率 |
| > profit_unreal | String | 是 | 未实现盈亏 |
| > available_margin | String | 是 | 可用保证金 |
| > voucher_value | String | 是 | 体验金(usdt) |
| > created_time | String | 是 | 账户创建时间 |
| > updated_time | String | 是 | 账户更新时间 |
| > details | String | 是 | 币种详细信息 |
| >> currency | String | 是 | 币种 |
| >> equity | String | 是 | 该币种全仓权益<br>detail.equity(币种全仓权益) = detail.available(币种全仓余额) + detail.profit_unreal（全仓未实现盈亏） |
| >> available | String | 是 | 该币种全仓余额 |
| >> available_margin | String<br> | 是 | 该币种全仓可用保证金<br>detail.available_margin(币种全仓可用) = detail.available(币种全仓余额) + detail.profit_unreal（全仓未实现盈亏）- detail.initial_margin(该币种全仓初始保证金) |
| >> maintenance_margin_rate | String | 是 | 该币种全仓维持保证金率 |
| >> profit_unreal | String | 是 | 全仓未实现盈亏 |
| >> initial_margin | String | 是 | 该币种全仓初始保证金 |
| >> maintenance_margin | String | 是 | 该币种全仓维持保证金 |
| >> initial_margin_rate | String | 是 | 该币种全仓初始保证金率 |
| >> voucher | String | 是 | 体验金 |
| >> voucher_value | String | 是 | 体验金(usdt) |
| >> isolated_equity | String | 是 | 该币种逐仓资产权益 |
| >> isolated_profit_unreal | String | 是 | 该币种逐仓未实现盈亏 |
| >> withdraw_available | String | 是 | 该字段已废弃，请忽略 |
| >> updated_time | String | 是 | 更新时间 |
| >> created_time | String | 是 | 创建时间 |
| >> isolated_available | String | 是 | 该币种逐仓可用资产 |
