# /v5/algo/order/opens (查看当前策略委托)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b7345a20e

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户查询当前未触发的策略委托 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 交易对 |
| algo_id | String | 否 | 策略订单 ID |
| algo_client_order_id | String | 否 | 用户自定义策略订单ID |
| type | String | 是 | 订单类型<br><br>tp：止盈<br>sl: 止损<br>tpsl: 止盈止损<br>trigger：计划委托<br>trailing_stop：跟踪委托 |
| from | long | 否 | 查询的起始id，默认从0开始 |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100 |
| direct | String | 否 | 翻页方向，prev, next，默认next |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| algo_id | String | 是 | 策略委托单ID |
| algo_client_order_id | String | 否 | 客户自定义策略订单ID |
| contract_code | String | 是 | 交易对名称 |
| volume | String | 是 | 委托张数 |
| type | String | 是 | 订单类型<br><br>tp：止盈<br>sl: 止损<br>tpsl: 止盈止损<br>trigger：计划委托<br>trailing_stop：跟踪委托 |
| state | String | 是 | 状态<br><br>active：等待触发 |
| position_side | String | 是 | 持仓方向<br><br>"long":多<br><br>"short":空<br><br>“both”:单向持仓 |
| margin_mode | String | 是 | 交易模式 |
| side | String | 是 | 订单方向<br><br>buy<br><br>sell |
| tp_trigger_price | String | 否 | 止盈触发价格 |
| tp_order_price | String | 否 | 止盈委托价格（最优N档委托类型时无需填写价格） |
| tp_type | String | 否 | 止盈委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark：标记价格 |
| sl_trigger_price | String | 否 | 止损触发价格 |
| sl_order_price | String | 否 | 止损委托价格（最优N档委托类型时无需填写价格） |
| sl_type | String | 否 | 止损委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark: 标记价格 |
| price | String | 否 | 计划委托价格 |
| price_match | String | 否 | 计划委托价格最优档位<br><br>opponent：对手价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档 |
| trigger_price | String | 否 | 计划委托触发价格 |
| trigger_price_type | String | 否 | 计划委托触发价格类型。枚举last, index, mark；默认是last |
| active_price | String | 否 | 跟踪委托激活价格。如果不填写激活价格，即下单后就被激活。 |
| order_price_type | String | 否 | 跟踪委托价格最优档位<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>formula_price：理论价格 |
| callback_rate | String | 否 | 回调幅度的比例，如 "0.05"代表"5%" |
| reduce_only | Boolean | 否 | 只减仓 |
| created_time | String | 是 | 订单创建时间, UTC时间戳(MS) |
| updated_time | String | 是 | 订单更新时间, UTC时间戳(MS) |
| order_source | String | 是 | 订单来源<br><br>system:系统、<br>web:用户网页、<br>api:用户API、<br>m:用户M站、<br>risk:风控系统、<br>settlement:交割结算、<br>ios：ios客户端、<br>android：安卓客户端、<br>windows：windows客户端、<br>mac：mac客户端、<br>trigger：计划委托触发、<br>tpsl:止盈止损触发、<br>ADL: adl订单 |
