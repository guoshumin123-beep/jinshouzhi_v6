# /v5/algo/cancel_orders (撤销策略委托订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73242ab0

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户撤销策略委托的订单,支持最多10个 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| algo_id | String | 否 | 策略委托单ID |
| algo_client_order_id | String | 否 | 客户订单ID |
| contract_code | String | 是 | 交易对 |

**请求参数说明**：algo_id和algo_client_order_id必须传一个，若两个都传，以 algo_id为准。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| algo_id | String | 是 | 订单ID |
| algo_client_order_id | String | 是 | 客户订单ID |
