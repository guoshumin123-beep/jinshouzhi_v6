# /v5/algo/order (策略委托下单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b72756dd7

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户创建策略委托的订单 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| type | String | 是 | 订单类型<br><br>tp: 止盈<br>sl: 止损<br>tpsl: 止盈止损<br>trigger: 计划委托<br>trailing_stop: 跟踪委托 |
| position_side | String | 是 | 仓位方向<br><br>long: 多<br>short: 空<br>both: 单向持仓，开平模式必填，买卖模式默认为both。 |
| side | String | 是 | 订单方向<br><br>buy:买<br><br>sell:卖 |
| algo_client_order_id | String | 否 | 客户端策略订单id |
| margin_mode | String | 是 | 保证金模式<br><br>isolated：逐仓<br><br>cross：全仓 |
| volume | String | 否 | 委托张数 |
| tp_trigger_price | String | 否 | 止盈触发价格<br><br>适用于止盈/止盈止损委托 |
| tp_order_price | String | 否 | 止盈委托价格（最优N档委托类型时无需填写价格）<br><br>适用于止盈/止盈止损委托 |
| tp_type | String | 否 | 止盈委托类型<br><br>market: 市价<br>limit: 限价<br>optimal_5: 最优5档<br>optimal_10: 最优10档<br>optimal_20: 最优20档<br><br>不填默认为market<br>适用于止盈/止盈止损委托 |
| tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark：标记价格<br><br>适用于止盈/止盈止损委托 |
| sl_trigger_price | String | 否 | 止损触发价格<br><br>适用于止损/止盈止损委托 |
| sl_order_price | String | 否 | 止损委托价格（最优N档委托类型时无需填写价格）<br><br>适用于止损/止盈止损委托 |
| sl_type | String | 否 | 止损委托类型<br><br>market: 市价<br>limit: 限价<br>optimal_5: 最优5档<br>optimal_10: 最优10档<br>optimal_20: 最优20档<br><br>不填默认为market<br>适用于 止损/止盈止损委托 |
| sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark: 标记价格<br><br>适用于止损/止盈止损委托 |
| price | String | 否 | 委托价格<br><br>适用于计划委托 |
| price_match | String | 否 | 最优档位<br>optimal_5：最优5档<br>optimal_10：最优10档<br>optimal_20：最优20档<br>适用于计划委托 |
| trigger_price | String | 否 | 计划委托触发价格<br><br>适用于计划委托 |
| trigger_price_type | String | 否 | 计划委托触发价格类型<br><br>last: 最新价<br><br>默认是last<br>适用于计划委托 |
| active_price | String | 否 | 激活价格。如果不填写激活价格，即下单后就被激活。<br><br>适用于跟踪委托 |
| order_price_type | String | 否 | 最优档位<br><br>optimal_5: 最优5档<br>optimal_10: 最优10档<br>optimal_20: 最优20档<br>formula_price: 理论价格<br><br>适用于跟踪委托 |
| callback_rate | String | 否 | 回调幅度的比例，如 "0.05"代表"5%"<br><br>适用于跟踪委托 |
| reduce_only | Boolean | 否 | 只减仓<br><br>适用于跟踪委托 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| algo_id | string | 是 | 订单ID |
| algo_client_order_id | string | 是 | 客户订单ID |

## 请求示例
```http
# 止盈止损策略单
POST /v5/algo/order  
{
    "contract_code": "ETH-USDT",
    "type": "tpsl",
    "position_side": "long",
    "side": "sell",
    "algo_client_order_id": "314499733684306",
    "margin_mode": "cross",
    "volume": 1,
    "tp_trigger_price": "800000",
    "tp_type": "market",
    "tp_trigger_price_type": "last",
    "sl_trigger_price": "100",
    "sl_type": "market",
    "sl_trigger_price_type": "last"
}  
 
# 计划委托策略单
POST /v5/algo/order  
{
    "contract_code": "ETH-USDT",
    "type": "trigger",
    "position_side": "long",
    "side": "buy",
    "algo_client_order_id": "",
    "margin_mode": "isolated",
    "volume": "1",
    "price": "1000",
    "trigger_price": "1000",
    "trigger_price_type":"last"
}
 
# 跟踪委托订单
POST /v5/algo/order
{
    "contract_code": "ETH-USDT",
    "type": "trailing_stop",
    "position_side": "long",
    "side": "sell",
    "algo_client_order_id": "",
    "margin_mode": "isolated",
    "volume": "1",
    "active_price": "100500",
    "order_price_type": "optimal_5",
    "callback_rate": "0.05",
    "reduce_only": false
}
```
