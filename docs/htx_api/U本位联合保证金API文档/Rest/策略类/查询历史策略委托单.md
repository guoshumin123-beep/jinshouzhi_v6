# /v5/algo/order/history (查询历史策略委托单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b7361ac19

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户查询策略订单历史信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码 |
| margin_mode | String | 否 | 保证金模式<br>cross：全仓 <br>isolated: 逐仓 |
| states | String | 否 | 可以查多个状态，使用逗号分隔。<br><br>effective：完全触发<br>canceled：完全取消<br>failed: 失败 |
| type | String | 是 | 订单类型；<br>tp：止盈<br>sl: 止损<br>tpsl: 止盈止损<br>trigger：计划委托<br>trailing_stop：跟踪委托 |
| start_time | String | 否 | 查询开始时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。<br><br>取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值 (now) – 48h。 |
| end_time | String | 否 | 查询结束时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。<br><br>取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值：now |
| from | Long | 否 | 查询的起始id，默认从0开始 |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |
| direct | String | 否 | 翻页方向<br><br>prev, next，默认next |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| algo_id | String | 是 | 策略委托单ID |
| algo_client_order_id | String | 是 | 客户自定义策略订单ID |
| contract_code | String | 是 | 交易对名称 |
| volume | String | 否 | 委托张数 |
| type | String | 是 | 订单类型 |
| state | String | 是 | 状态<br><br>effective：完全触发<br><br>canceled：完全取消<br><br>failed: 失败 |
| position_side | String | 是 | 持仓方向<br><br>"long":多<br><br>"short":空<br><br>“both”:单向持仓 |
| margin_mode | String | 是 | 交易模式 |
| side | String | 是 | 订单方向 |
| tp_trigger_price | String | 否 | 止盈触发价格 |
| tp_order_price | String | 否 | 止盈委托价格（最优N档委托类型时无需填写价格） |
| tp_type | String | 否 | 止盈委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark：标记价格 |
| sl_trigger_price | String | 否 | 止损触发价格 |
| sl_order_price | String | 否 | 止损委托价格（最优N档委托类型时无需填写价格） |
| sl_type | String | 否 | 止损委托类型<br><br>market: 市价<br><br>limit：限价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>不填默认为market |
| sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价<br><br>last: 最新价<br><br>mark: 标记价格 |
| price | String | 否 | 计划委托价格 |
| price_match | String | 否 | 计划委托价格最优档位<br><br>opponent：对手价<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档 |
| trigger_price | String | 否 | 计划委托触发价格 |
| trigger_price_type | String | 否 | 计划委托触发价格类型。枚举last, index, mark；默认是last |
| active_price | String | 否 | 跟踪委托激活价格。如果不填写激活价格，即下单后就被激活。 |
| order_price_type | String | 否 | 跟踪委托最优档位<br><br>optimal_5：最优5档<br><br>optimal_10：最优10档<br><br>optimal_20：最优20档<br><br>formula_price：理论价格 |
| callback_rate | String | 否 | 回调幅度的比例，如 "0.05"代表"5%" |
| reduce_only | Boolean | 否 | 只减仓 |
| actual_volume | String | 否 | 实际触发数量 |
| actual_price | String | 否 | 实际触发价格 |
| actual_time | String | 否 | 策略触发时间 |
| created_time | String | 是 | 订单创建时间, UTC时间戳(MS) |
| updated_time | String | 是 | 订单更新时间, UTC时间戳(MS) |
| order_source | String | 是 | 订单来源<br><br>system:系统、<br><br>web:用户网页、<br><br>api:用户API、<br><br>m:用户M站、<br><br>risk:风控系统、<br><br>settlement:交割结算、<br><br>ios：ios客户端、<br><br>android：安卓客户端、<br><br>windows：windows客户端、<br><br>mac：mac客户端、<br><br>trigger：计划委托触发、<br><br>tpsl:止盈止损触发、<br><br>ADL: adl订单 |
| relation_order_id | String | 否 | 触发后关联的普通订单id |

## 请求示例
```http
GET /v5/algo/order/history?type=trigger
```
