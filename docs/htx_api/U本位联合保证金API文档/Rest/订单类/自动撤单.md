# /v5/trade/cancel-after (自动撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b72307cbb

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) |
| 接口描述 | 为了防止API用户在发生网络故障或用户端系统故障与火币系统失去联系时，给用户造成意外损失，火币合约业务提供自动撤单接口，当用户与火币发生意外断连时，能自动帮用户取消全部挂单（仅包含开仓&平仓单）以避免损失，即提供Dead man's switch功能。若开启在设定的时间数完前接口没有被再次调用，则用户所有合约挂单将被取消 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| on_off | String | 是 | 自动撤单功能开启和关闭1：开启功能;0：关闭功能 |
| time_out | String | 否 | 设置自动撤单倒计时时间，超过时间未关闭功能将取消客户名下所有挂单。开启撤单功能时建议设置，否则默认5000毫秒（5s）倒计时。大于等于5000毫秒。<br>默认为5000毫秒。 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| current_time | String | 是 | 当前时间(以平台服务器时间为准），UNIX时间戳，以毫秒为单位。 |
| trigger_time | String | 是 | 触发时间(以平台服务器时间为准），UNIX时间戳，以毫秒为单位。 |

## 请求示例
```http
{
    "on_off":"1",
    "time_out":"5000"
}
```

