# /v5/trade/cancel_order (撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957defffc6

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于撤销合约订单。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| order_id | String | 否 | 订单ID |
| client_order_id | String | 否 | 客户订单ID |

**请求参数说明**：order_id和client_order_id必须传一个，若两个都传，以order_id为准

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order_id | String | 是 | 订单ID |
| client_order_id | String | 是 | 客户订单ID |

## 请求示例
```http
{
    "contract_code": "BTC-USDT-241115",
    "order_id": 1329854625038651392,
    "client_order_id": 1329854625038651392
}
```

## 响应示例
```json
{"code": 200,
 "data": {"client_order_id": "1329854625038651392",
          "order_id": "1329854625038651392"},
 "message": "Success",
 "ts": 1737104050245}
```

## 失败示例
```json
{
  "code": 1061,
  "message": "The order does not exist.",
  "data": null,
  "ts": 1782119905956
}
```
