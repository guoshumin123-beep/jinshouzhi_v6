# /v5/trade/cancel_batch_orders (批量撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957df2abbe

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) |
| 接口描述 | 此接口用于批量撤销合约订单，最多可以撤销10个 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| order_id | Array of string | 否 | 订单ID |
| client_order_id | Array of string | 否 | 客户订单ID |

**请求参数说明**：order_id和client_order_id必须传一个，若两个都传，已order_id为准。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order_id | string | 是 | 订单ID |
| client_order_id | string | 是 | 客户订单ID |
