# /v5/trade/cancel_all_orders (全部撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957df6feb3

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) |
| 接口描述 | 撤销当前全部的挂单（不含策略单）。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |
| 线上环境 | `https://api.hbdm.com` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码 |
| side | String | 否 | 订单方向buy:买 "sell":卖 |
| position_side | String | 否 | 仓位方向"long":多 "short":空 “both”:单向持仓 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order_id | string	 | 是 | 订单ID |
| client_order_id | string | 是 | 客户订单ID |

## 请求示例
```http
{
    "contract_code": "BTC-USDT-241115",
    "side": "buy",
    "position_side": "long"
}
```
