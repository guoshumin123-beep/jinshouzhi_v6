# /v5/trade/batch_orders (批量下单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957de4ff8f

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 接口用户合约批量下单交易 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 否 | 开平方向"long":多 "short":空 “both”:单向持仓，开平模式必填，买卖模式默认为both。 |
| side | String | 是 | 订单方向buy:买 "sell":卖 |
| type | String | 是 | 订单类型；枚举"market": 市价，"limit":限价, "post_only":只挂单 |
| price_match | String | 否 | 最优档位，和price互斥 opponent-对手价、opponent-对手价、"optimal_5"：最优5档，"optimal_10"：最优10档，"optimal_20"：最优20档 |
| client_order_id | String | 否 | 用户自定义订单ID[1-9223372036854775807] |
| price | String | 否 | 价格，仅当限价单的时候有效，市价无需输入。 |
| volume | String | 是 | 委托张数。 |
| reduce_only | Boolean | 否 | 只减仓 0-否，1-是 |
| time_in_force | String | 否 | 枚举fok, ioc, gtc，rpi，非必填，默认是gtc |
| tp_trigger_price | String | 否 | 止盈触发价格 |
| tp_order_price | String | 否 | 止盈委托价格（最优N档委托类型时无需填写价格） |
| tp_type | String | 否 | 止盈委托类型,不填默认为market: 市价，maket: 限价：limit ，最优5档： optimal_5，最优10档：optimal_10，最优20档：optimal_20 |
| tp_trigger_price_type | String | 否 | 止盈价格触发类型，默认是最新价"last":最新价，"mark"：标记价格 |
| sl_trigger_price | String | 否 | 止损触发价格 |
| sl_order_price | String | 否 | 止损委托价格（最优N档委托类型时无需填写价格） |
| sl_type | String | 否 | 止损委托类型,不填默认为 市价，maket: 限价：limit ，最优5档： optimal_5，最优10档：optimal_10，最优20档：optimal_20 |
| sl_trigger_price_type | String | 否 | 止损价格触发类型，默认是最新价"last":最新价，"mark"：标记价格 |
| price_protect | boolean | 否 | 价差保护，默认为false。仅当设置止盈/止损需要该参数。false 或者 true |
| self_match_prevent | String | 否 | 防自成交cancel_taker ：撤销taker单 cancel_maker：撤销maker单 cancel_both：撤销全部订单 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order_id | String | 是 | 订单ID |
| client_order_id | String | 是 | 用户下单时填写的客户端订单ID，没填则不返回 |

**响应参数说明**：备注:
position_side持仓方向
单向持仓模式下此参数非必填
如果填写仅可以选择both；在双向持仓模式下必填，且仅可选择 long 或 short。
双向持仓模式下，side和position_side需要进行组合
买入开多（side 填写 buy； position_side 填写 long ）
卖出开空（side 填写 sell； position_side 填写 short ）
卖出平多（side 填写 sell；position_side 填写 long ）
买入平空（side 填写 buy； position_side 填写 short ）
单向持仓模式下，多仓返回buy，空仓返回sell
