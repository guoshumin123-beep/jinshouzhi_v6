# /v5/trade/order/details (查询成交明细（近三天）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957e2a0e6a

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于查询合约进3天订单成交明细 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| order_id | String | 否 | 订单的订单 ID |
| start_time | String | 否 | 查询开始时间，UNIX时间戳，以毫秒为单位。取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近90天。 默认值 (now) – 48h |
| end_time | String | 否 | 查询结束时间，UNIX时间戳，以毫秒为单位。取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天。 默认值：now |
| from | Long | 否 | 查询的起始id，默认从0开始 |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |
| direct | String | 否 | 翻页方向，prev, next，默认next |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| contract_code | String | 是 | 合约代码永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| order_id | String | 是 | 订单ID |
| trade_id | String | 是 | 成交id |
| side | String | 是 | 交易方向，buy表示买，sell表示卖。 |
| position_side | String | 是 | 仓位方向"long":多 "short":空 “both”:单向持仓 |
| order_type | String | 是 | 成交类型 "1":"trade", "3":"liquidation" ,"4":"delivery","22":"adl" |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| type | String | 是 | 订单类型；枚举market, limit, post_only |
| role | String | 是 | 成交角色maker, taker |
| trade_price | String | 是 | 成交价格 |
| trade_volume | String | 是 | 成交量（张） |
| trade_turnover | String | 是 | 成交金额（成交数量 * 合约面值 * 成交价格） |
| created_time | String | 是 | 创建时间 |
| updated_time | String | 是 | 更新时间，默认为撮合成交时间 |
| order_source | String | 是 | 订单来源；system:系统、web:用户网页、api:用户API、m:用户M站、risk:风控系统、settlement:交割结算、ios：ios客户端、android：安卓客户端、windows：windows客户端、mac：mac客户端、trigger：计划委托触发、tpsl:止盈止损触发、ADL: adl订单） |
| fee_currency | String | 是 | 手续费币种 |
| trade_fee | String | 是 | 手续费(U) |
| deduction_price | String | 是 | 抵扣币种价格(USDT) |
| profit | String | 是 | 平仓盈亏 |
| contract_type | String | 是 | 合约类型swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季） |
