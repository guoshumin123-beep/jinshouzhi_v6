# /v5/trade/position (市价全平)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957e02b018

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于市价卖出指定的持仓 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 是 | 仓位方向持仓方向 买卖模式下默认值both， 开平仓模式下： long：多 ，short：空 |
| client_order_id | String | 否 | 用户自定义订单ID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order_id | String | 是 | 订单ID[全局唯一] |
| client_order_id | String | 否 | 用户自己的订单id |

## 请求示例
```http
{
    "contract_code": "BTC-USDT-241129",
    "margin_mode": "cross",
    "position_side": "long",
    "client_order_id": "1330969352647610368"
}
```

## 响应示例
```json
{"code": 200,
 "data": {"client_order_id": "1330969352647610368",
          "order_id": 1339200243479453696},
 "message": "Success",
 "ts": 1739331819194}
```
