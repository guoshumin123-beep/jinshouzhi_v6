# /v5/position/mode (设置持仓模式)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957f4ec40b

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| position_mode | string | 是 | 持仓模式single_side：单向持仓；dual_side：双向持仓 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| position_mode | string | 是 | 持仓模式single_side：单向持仓；dual_side：双向持仓 |

## 请求示例
```http
POST /v5/position/mode
{
    "position_mode": "dual_side"
}
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": {
        "position_mode": "dual_side"
    },
    "ts": 1740463132267
}
```
