# /v5/trade/position/opens (查询当前持仓)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957f1fbee4

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于查询当前用户持仓仓位的信息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | string | 否 | 合约代码永续："BTC-USDT"... ， 交割：“BTC-USDT-210625” ... |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码 |
| position_side | String | 是 | 仓位方向持仓方向 买卖模式下默认值both， 开平仓模式下： long：平多 |
| direction | String | 是 | 订单方向"buy":买， "sell":卖 |
| open_avg_price | String | 是 | 开仓均价 |
| margin_mode | String | 是 | 保证金模式cross：全仓<br>isolated：逐仓 |
| volume | String | 是 | 持仓量（张 |
| available | String | 是 | 可平仓数量（张） |
| lever_rate | Long | 是 | 杠杠倍数 |
| adl_risk_percent | Int | 是 | 自动减仓指示(1、2、3、4、5)，1档风险最低，5档风险最高 |
| liquidation_price | String | 是 | 预估强平价 |
| initial_margin | String | 是 | 初始保证金，仅适用于全仓 |
| maintenance_margin | String | 是 | 维持保证金 |
| margin | String | 是 | 为全仓时代表初始保证金，为逐仓时代表仓位保证金 |
| profit_unreal | String | 是 | 未实现盈亏 |
| profit_rate | String | 是 | 未实现收益率 |
| margin_rate | String | 是 | 保证金率-对标调整信息 |
| margin_currency | String | 是 | 保证金币种（计价币种） |
| last_price | String | 是 | 最新价格 |
| mark_price | decimal | 是 | 标记价格 |
| contract_type | String | 是 | 合约类型swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季） |
| created_time | String | 是 | 创建时间 |
| updated_time | String | 是 | 更新时间 |

## 请求示例
```http
{"contract_code": "eth-usdt"}
```
