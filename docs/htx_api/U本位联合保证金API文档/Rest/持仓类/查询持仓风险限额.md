# /v5/position/risk/limit (查询持仓风险限额)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957f50bd39

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) |
| 接口描述 | 查询当前持有的合约持仓风险限额阶梯信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码"BTC-USDT","ETH-USDT20241109"…… |
| margin_mode | String | 否 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 否 | 仓位方向long:多，short:空，both：单向持仓 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT20241109"…… |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 是 | 仓位方向long:多，short:空，both：单向持仓 |
| max_lever | String | 是 | 该层最大杠杆等级 |
| maintenance_margin_rate | String | 是 | 该层维持保证率 |
| max_volume | String | 是 | 该层最高持有数量 |
| min_volume | String | 是 | 该层最低持有数量 |
| volume_unit | String | 是 | 持有单位contract: 张 usdt：USDT |

## 请求示例
```http
{
           "contract_code": "BTC-USDT",
           "margin_mode": "cross",
           "position_side": "short"
       }
```
