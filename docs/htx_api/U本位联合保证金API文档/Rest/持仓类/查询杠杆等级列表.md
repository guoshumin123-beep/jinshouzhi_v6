# /v5/position/lever (查询杠杆等级列表)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957f316730

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户查询出杠杆等级的列表 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码"BTC-USDT","ETH-USDT"…… |
| margin_mode | String | 否 | 保证金模式cross：全仓 <br>isolated：逐仓<br>默认为 cross |
| position_side | String | 否 | 持仓方向long: 多仓<br>short: 空仓<br>both: 单向持仓 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT"…… |
| contract_type | String | 是 | 合约类型swap（永续）、this_week（当周）、next_week（次周）、quarter（当季）、next_quarter（次季） |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 是 | 持仓方向long: 多仓<br>short: 空仓<br>both: 单向持仓 |
| lever_rate | Long | 是 | 杠杆等级 |
| available_lever | List | 是 | 可用杠杆等级可用杠杆倍数 |

## 请求示例
```http
GET /v5/position/lever?margin_mode=cross&contract_code=BTC-USDT&position_side=long
```
