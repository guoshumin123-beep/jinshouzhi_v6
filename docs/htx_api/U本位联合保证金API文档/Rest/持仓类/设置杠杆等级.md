# /v5/position/lever (设置杠杆等级)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957f4a3b67

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户查询出杠杆等级的列表 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT"…… |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 否 | 持仓方向<br><br>逐仓模式下且为双向持仓模式，该字段必填。<br><br>逐仓模式下且为单向持仓模式，该字段不必传。<br><br>全仓模式下，多空杠杆一致。该字段不必传。long: 多仓<br>short: 空仓<br>both: 单向持仓 |
| lever_rate | String | 是 | 杠杆等级目标杠杆等级 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT"…… |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| position_side | String | 是 | 持仓方向long: 多仓<br>short: 空仓<br>both: 单向持仓 |
| lever_rate | String | 是 | 杠杆等级目标杠杆等级 |

## 请求示例
```http
{
    "contract_code": "BTC-USDT",
     "margin_mode":"cross",
    "position_side": "long",
    "lever_rate": 5
}
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": {
        "contract_code": "BTC-USDT",
        "margin_mode": "cross",
        "position_side": "long",
        "lever_rate": 5
    },
    "ts": 1740452492265
}
```
