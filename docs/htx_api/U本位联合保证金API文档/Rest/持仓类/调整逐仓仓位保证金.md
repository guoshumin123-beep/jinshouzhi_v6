# /v5/position/margin (调整逐仓仓位保证金)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b7247e4dd

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 用于增加或减少逐仓持仓的保证金，通过“/linear-swap-api/v3/unified_account_info”可以查询对应逐仓持仓可以增加或减少的保证金(单位为 USDT)，可增加保证金值通过“margin_available”字段确定，可减少保证金值通过“withdraw_available”字段确认。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT"…… |
| position_side | String | 是 | 仓位方向long：多<br>short：空<br>both：买卖模式 |
| type | String | 是 | 调整类型add：增加<br>reduce：减少 |
| amount | String | 是 | 保证金金额，单位为 USDT |

## 请求示例
```http
{
    "contract_code":"BTC-USDT",
    "position_side":"long",
    "amount":"10",
    "type":"add"
}
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": null,
    "ts": 1767149479430
}
```
