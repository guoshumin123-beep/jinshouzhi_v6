# /v5/market/elite_account_ratio (查询精英账户多空持仓对比-账户数)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73bd8472

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码永续："BTC-USDT"... , 交割："BTC-USDT-FUTURES" ... |
| period | String | 是 | 时间周期类型5min, 15min, 30min, 60min,4hour,1day |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code<br> | String | 是 | 交易对 |
| buy_ratio | String | 是 | 净多仓的账户比例 |
| sell_ratio | String | 是 | 净空仓的账户比例 |
| ts | String | 是 | 数据生成时间，UNIX时间戳，以毫秒为单位。 |

## 请求示例
```http
GET /v5/market/elite_account_ratio?contract_code=BTC-USDT&period=5min
```

## 响应示例
```json
{ 
"code": 0, 
"msg": "success", 
"data": { 
"contract_code": "BTC-USDT", 
"buy_ratio": "0.582", 
"sell_ratio": "0.418", 
"ts": "1741248647000" 
} 
}
```
