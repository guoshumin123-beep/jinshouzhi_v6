# /v5/market/estimated_settlement_price (查询预估结算价)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73c587fc

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | - |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询平台预估结算价格 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 交易对 |
| settlement_type | String | 是 | 结算<br>类型“delivery”：交割，“settlement”：结算 |
| estimated_settlement_price | String | 是 | 本期预估结算价格 |

**响应参数说明**：结算类型为结算时，预估结算价字段（estimated_settlement_price）在结算前10分钟到结算开始才计算和更新展示，其他时间点（包括结算中）则estimated_settlement_price为空，其他字段正常展示。
结算类型为交割时，预估交割价字段（estimated_settlement_price）在交割前10分钟到交割开始才计算和更新展示，其他时间点（包括交割中）则estimated_settlement_price为空，其他字段正常展示。
每6秒计算并更新一次预估结算价。

## 请求示例
```http
/v5/market/estimated_settlement_price?contract_code=BTC-USDT
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": [
        {
            "contract_code": "BTC-USDT",
            "settlement_type": "settlement",
            "estimated_settlement_price": "126708.743"
        }
    ],
    "ts": 1767695459714
}
```
