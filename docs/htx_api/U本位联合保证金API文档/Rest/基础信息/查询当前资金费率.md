# /v5/market/funding_rate (查询当前资金费率)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b738520e0

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询当前的资金费率信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 交易对名称。使用逗号分隔，可查询多个，最多查询10个 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| funding_rate | String | 是 | 当期资金费率 （一分钟计算一次） |
| funding_time | String | 是 | 当期资金费率时间 |
| next_funding_time | String | 是 | 下一期资金费率时间 |
| min_funding_rate | String | 是 | 资金费率下限，如 0.01 代表 1% |
| max_funding_rate | String | 是 | 资金费率上限，如 0.01 代表 1% |

## 请求示例
```http
GET /v5/market/funding_rate?contract_code=BTC-USDT
```
