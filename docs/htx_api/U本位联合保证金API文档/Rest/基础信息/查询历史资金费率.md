# /v5/market/funding_rate_history (查询历史资金费率)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b7389e8ee

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询历史的资金费率信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625".. |
| start_time | String | 否 | 查询开始时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值 (now) – 48h |
| end_time | String | 否 | 查询结束时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值：now |
| from | String | 否 | 查询的起始id，默认从0开始 |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |
| direct | String | 否 | 翻页方向prev, next，默认next |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| contract_code | String | 是 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| funding_rate | String | 是 | 当期资金费率 |
| funding_time | String | 是 | 当期资金费率时间 |
| funding_fee_type | String | 是 | 资金费类型normal：普通资金费；dividend_settlement：特殊股息资金费 |

## 请求示例
```http
GET /v5/market/funding_rate_history?contract_code=ETH-USDT
```
