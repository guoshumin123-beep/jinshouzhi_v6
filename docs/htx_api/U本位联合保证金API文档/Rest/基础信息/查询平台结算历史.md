# /v5/market/settlement_history (查询平台结算历史)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73b16e57

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询平台结算历史信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| start_timeend_time | String | 否 | 查询开始时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值 (now) – 48h |
| end_time | String | 否 | 查询结束时间, 以数据按创建时间进行查询，UNIX时间戳，以毫秒为单位。取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br>默认值：now |
| direct | String | 否 | 查询方向, 方向为next时，数据按照时间正序排列返回，方向为prev时，数据按照时间倒序返回prev表示向前查询，next表示向后查询。<br>默认值：next |
| from | String | 否 | 如果是向前(prev)查询，则赋值为上一次查询结果中得到的最小query_id ；如果是向后(next)查询，则赋值为上一次查询结果中得到的最大query_id |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id，可作为下一次查询请求的from字段 |
| contract_code | String | 是 | 合约代码永续："BTC-USDT"... , 交割：“BTC-USDT-210625”... |
| settlement_time | String | 是 | 结算时间（时间戳，单位毫秒）（当settlement_type为交割时，该时间为交割时间；当settlement_type为结算时，该时间为结算时间；） |
| clawback_ratio | String | 是 | 分摊比例 |
| settlement_price | String | 是 | 结算价格（当settlement_type为交割时，该价格为交割价格；当settlement_type为结算时，该价格为结算价格；） |

## 请求示例
```http
GET /v5/market/settlement_history?contract_code=BTC-USDT
```
