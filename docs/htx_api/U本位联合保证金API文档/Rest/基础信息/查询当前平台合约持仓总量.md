# /v5/market/open_interest (查询当前平台合约持仓总量)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73998b8f

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询当前平台的合约总持仓量 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码永续："BTC-USDT"... ，交割："BTC-USDT-210625"... |
| amount | String | 是 | 持仓量(币)，单边数量 |
| volume | String | 是 | 持仓量(张)，单边数量 |
| value | String | 是 | 总持仓额（单位为合约的计价币种，如USDT） |
| trade_amount | String | 是 | 最近24小时成交量（币）（当前时间-24小时）,值是买卖双边之和 |
| trade_volume | String | 是 | 最近24小时成交量（张）（当前时间-24小时）,值是买卖双边之和 |
| trade_turnover | String | 是 | 最近24小时成交额 （当前时间-24小时）,值是买卖双边之和 |

## 请求示例
```http
GET /v5/market/open_interest?contract_code=BTC-USDT
```

## 响应示例
```json
{
    "code": 200,
    "data": {
        "amount": "244.004",
        "volume": "244004",
        "value": "29275599.92",
        "contract_code": "BTC-USDT",
        "trade_amount": "9.838",
        "trade_volume": "9838",
        "trade_turnover": "1091416.458752"
    },
    "message": null,
    "success": true
}
```
