# /v5/market/risk/limit (查询合约风险限额)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-195809dc1e8

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询合约风险限额表相关信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码，使用逗号分隔，最多不可超过10个"BTC-USDT","ETH-USDT-241109"…… |
| margin_mode | string | 否 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| tier | string | 否 | 查指定档位 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码"BTC-USDT","ETH-USDT"…… |
| margin_mode | String | 是 | 保证金模式cross：全仓 <br>isolated：逐仓 |
| tier | String | 是 | 层级 |
| max_lever | String | 是 | 该层最大杠杆等级 |
| maintenance_margin_rate | String | 是 | 该层维持保证率 |
| max_volume | String | 是 | 该层最高持有数量 |
| min_volume | String | 是 | 该层最低持有数量 |
| volume_unit | String | 是 | 持有单位contract: 张 usdt：USDT |

## 请求示例
```http
{
    "contract_code": "BTC-USDT"
}
```
