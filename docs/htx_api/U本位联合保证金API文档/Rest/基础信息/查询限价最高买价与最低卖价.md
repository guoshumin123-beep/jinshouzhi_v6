# /v5/market/price_limit (查询限价最高买价与最低卖价)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73a247e7

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询限价最高买价与最低卖价 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 永续："BTC-USDT"...<br>交割："BTC-USDT-210625"... |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 是 | 合约代码永续："BTC-USDT"...<br>交割："BTC-USDT-210625"... |
| high_limit | String | 是 | 最高买价 |
| low_limit | String | 是 | 最低卖价 |

## 请求示例
```http
GET /v5/market/price_limit
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": [
        {
            "contract_code": "BTC-USDT",
            "high_limit": "88660640381.463",
            "low_limit": "0"
        }
    ],
    "ts": 1767150007969
}
```
