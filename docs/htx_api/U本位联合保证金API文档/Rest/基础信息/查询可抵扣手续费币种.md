# /v5/market/assets_deduction_currency (查询可抵扣手续费币种)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19580a209a2

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 此接口用于查询平台当前支持手续费可抵扣的币种列表。 |
| 接口描述 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | list | 是 | 币种 |

## 请求示例
```http
无
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": {
        "currency": [
            "HTX",
            "TRX"
        ]
    },
    "ts": 1740454112540
}
```
