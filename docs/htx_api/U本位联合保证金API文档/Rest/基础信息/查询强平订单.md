# /v5/market/liquidation_orders (查询强平订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b73ab3d66

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 每个IP3秒最多240次请求（所有该IP的非行情类的公开接口请求共享3秒240次的额度） |
| 接口描述 | 查询平台强平订单的信息 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码<br>contract_code 和 pair 必须传一个。 |
| pair | String | 否 | 交易对BTC-USDT |
| start_time | String | 否 | 查询开始时间, 以数据按创建时间进行查询取值范围 [((end-time) – 2h), (end-time)] ，查询窗口最大为2小时，窗口平移范围为最近90天,已完全撤销的历史订单的查询窗口平移范围只有最近2小时 |
| end_time | String | 否 | 查询结束时间, 以数据按创建时间进行查询取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天,已完全撤销的历史订单的查询窗口平移范围只有最近2小时 |
| direct | String | 否 | 查询方向, 方向为next时，数据按照时间正序排列返回，方向为prev时，数据按照时间倒序返回prev表示向前查询，next表示向后查询。 |
| from | String | 否 | 如果是向前(prev)查询，则赋值为上一次查询结果中得到的最小id ；如果是向后(next)查询，则赋值为上一次查询结果中得到的最大id |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| id | String | 是 | 查询id |
| contract_code | String | 是 | 合约代码永续："BTC-USDT", 交割："BTC-USDT-210625" ... |
| liquidation_time | String | 是 | 强平时间 |
| side | String | 是 | 买卖方向buy:买 "sell":卖 |
| position_side | String | 是 | 开平方向"long":多 "short":空 “both”:单向持仓 |
| volume | String | 是 | 强平数量（张） |
| amount | String | 是 | 强平数量（币 |
| bankrupt_price | String | 是 | 破产价格 |
| trade_turnover | String | 是 | 强平金额（计价币种） |

## 请求示例
```http
GET /v5/market/liquidation_orders?contract_code=BTC-USDT
```
