# /v5/account/balance (查询账户余额)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-195703a12d5

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于查询合约账户信息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| state | String | 是 | 账户状态<br>"normal":正常（交易，划转）<br>"liquidating":强平中，不允许交易、划转、收取资金费、 <br>"adl":adl中，不允许交易、收取资金费、划转、<br>"open_limit":风控撤单中，合约交易只允许下减仓单，可以转入，不允许转出 |
| equity | String | 是 | 账户权益<br>单位为USD<br>适用于联合保证金模式 |
| initial_margin | String | 是 | 初始保证金，单位为USD<br>适用于联合保证金模式 |
| maintenance_margin | String | 是 | 维持保证金，单位为USD<br><br>适用于联合保证金模式 |
| maintenance_margin_rate | String | 是 | 维持保证金率<br><br>适用于联合保证金模式 |
| profit_unreal | String | 是 | 未实现盈亏，单位为USD<br><br>适用于联合保证金模式 |
| available_margin | String | 是 | 可用保证金，单位为USD<br><br>适用于联合保证金模式 |
| voucher_value | String | 是 | 体验金(usdt) |
| created_time | Long | 是 | 账户创建时间 |
| updated_time | Long | 是 | 账户更新时间 |
| details | List | 是 | 币种资产详情 |
| > currency | String | 是 | 币种 |
| > equity | String | 是 | 该币种全仓权益 |
| > isolated_equity | String | 是 | 该币种逐仓权益 |
| > available | String | 是 | 该币种全仓余额<br>detail.equity(币种全仓权益) = detail.available(币种全仓余额) + detail.profit_unreal（全仓未实现盈亏） |
| > isolated_available | String | 是 | 该币种逐仓可用资产。无逐仓持仓时返回 "0"。 |
| > withdraw_available | String | 是 | 该币种可转 |
| > profit_unreal | String | 是 | 该币种全仓未实现盈亏 |
| > isolated_profit_unreal | String | 是 | 该币种逐仓未实现盈亏 |
| > initial_margin | String | 是 | 该币种全仓初始保证金 |
| > maintenance_margin | String | 是 | 该币种全仓维持保证金 |
| > maintenance_margin_rate | String | 是 | 该币种全仓维持保证金率 |
| > initial_margin_rate | String | 是 | 该币种全仓初始保证金率 |
| > voucher | String | 是 | 体验金 |
| > voucher_value | String | 是 | 体验金(usdt) |
| > created_time | Long | 是 | 创建时间 |
| > updated_time | Long | 是 | 更新时间 |

**响应参数说明**：币种余额 = available + isolated_available
其中"币种余额"是指该币种在联合保证金账户中全部可用资产的总和（不含已作为保证金占用的部分）

## 请求示例
```http
GET /v5/account/balance
```
