# /v5/account/asset_mode (设置资产模式)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957dd1a995

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | UID: 1次/10s |
| 接口描述 | 此接口用户设置当前的资产金模式。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| asset_mode | int | 是 | 资产模式0:单币种保证金模式（老）<br>1:联合保证金模式<br>2:单币种保证金模式(新） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| asset_mode | int | 是 | 资产模式0:单币种保证金模式（老）<br>1:联合保证金模式<br>2:单币种保证金模式(新） |

## 请求示例
```http
POST /v5/account/asset_mode
{
    "asset_mode": 1
}
```

## 响应示例
```json
{
    "code": 200,
    "msg": "操作成功",
    "data":{
       "asset_mode":0
    },
    "ts": 1547521135713
}
```
