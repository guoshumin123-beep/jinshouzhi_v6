# /v5/account/asset_mode (查询资产模式)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1957dd37de0

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用户查询当前的资产模式。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| asset_mode | int | 是 | 资产模式0:单币种保证金模式（老）<br>1:联合保证金模式<br>2:单币种保证金模式(新） |

## 请求示例
```http
无
```

## 响应示例
```json
{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "asset_mode": 1
    },
    "ts": 1547521135713
}
```
