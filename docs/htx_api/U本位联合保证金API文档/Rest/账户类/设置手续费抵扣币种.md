# /v5/account/fee_deduction_currency (设置手续费抵扣币种)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-198826314c7

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于设置交易手续费抵扣币种，仅母用户可进行配置操作。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| fee_option | int | 是 | 是否开启抵扣1：是、0：否 |
| deduction_currency | String | 是 | 抵扣币种HTX |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| fee_option | int | 是 | 是否开启抵扣1：是、0：否 |
| deduction_currency | String | 是 | 抵扣币种HTX |

## 请求示例
```http
{
    "fee_option": 1,
    "deduction_currency":"htx"
}
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": {
        "fee_option": 1,
        "deduction_currency": "htx"
    },
    "ts": 1753154995073
}
```

## 失败示例
```json
{
    "code": 4012,
    "message": "该品种不支持抵扣",
    "data": null,
    "ts": 1753155036553
}
```
