# /v5/account/fee_deduction_currency (查看手续费抵扣币种)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b723f5241

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| fee_option | Int | 是 | 是否开启手续费抵扣1：是<br><br>0：否 |
| deduction_currency | String | 否 | 抵扣币种<br><br>当 fee_option = 0，不返回 |

## 请求示例
```http
GET /v5/account/fee_deduction_currency
```

## 响应示例
```json
{
    "code": 200,
    "message": "Success",
    "data": {
        "fee_option": 1,
        "deduction_currency": "htx"
    },
    "ts": 1767149708554
}
```
