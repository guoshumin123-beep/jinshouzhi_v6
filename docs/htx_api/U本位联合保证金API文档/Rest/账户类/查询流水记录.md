# /v5/account/bills (查询流水记录)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-19b724157a2

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 每个UID 3秒最多 144 次请求(交易接口3秒最多 72 次请求，查询接口3秒最多 72 次请求) (该UID的所有币种和不同到期日的合约的所有私有接口共享该限制) 。 |
| 接口描述 | 此接口用于查询财务流水记录 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.hbdm.com` |
| 线上环境（aws客户首选） | `https://api.hbdm.vn` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| contract_code | String | 否 | 合约代码"BTC-USDT","ETH-USDT"…… |
| margin_mode | String | 否 | 保证金模式cross：全仓，isolated: 逐仓 |
| start_time | String | 否 | 查询开始时间，UNIX时间戳，以毫秒为单位。取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br><br>默认值 (now) – 48h |
| type | String | 否 | 财务类型，不填查询全部类型,【查询多类型中间用，隔开】3:平多<br>4:平空<br>5:开仓手续费-吃单<br>6:开仓手续费-挂单<br>7:平仓手续费-吃单<br>8:平仓手续费-挂单<br>9:交割平多<br>10:交割平空<br>11:交割手续费<br>12:强制平多<br>13:强制平空<br>14:从币币转入<br>15:转出至币币<br>19:穿仓分摊<br>26:系统<br>28:活动奖励<br>29:返利<br>30:资金费-收入<br>31:资金费-支出<br>34:转出到子账号合约账户<br>35:从子账号合约账户转入<br>36:转出到母账号合约账户<br>37:从母账号合约账户转入<br>38:从其他保证金账户转入<br>39转出到其他保证金账户<br>85:（系统垫资账户-用户U本位账户（转出垫资账户)）<br>86:（用户U本位账户-系统垫资发放账户 (转入垫资账户)）<br>141:爆仓手续费<br>160:股息结算收入<br>161:股息结算支出 |
| end_time | String | 否 | 查询结束时间，UNIX时间戳，以毫秒为单位。取值范围 [(present-90d), present] ，查询窗口最大为48小时，窗口平移范围为最近90天。<br><br>默认值：now |
| from | Long | 否 | 查询的起始id，默认从0开始 |
| limit | Integer | 否 | 分页页面大小，默认为10，最大为100。 |
| direct | String | 否 | prev, next |
