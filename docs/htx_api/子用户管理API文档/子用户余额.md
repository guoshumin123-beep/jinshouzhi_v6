# /v1/account/accounts/{sub-uid} (子用户余额)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec40be1-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 母用户查询子用户各币种账户余额 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| sub-uid | long | 是 | 子用户的 UID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态<br>"OK" or "Error" |
| <data> | object | 是 |  |
| id | long | 是 | 账户ID |
| type | string | 是 | 账户类型<br>spot：现货账户，point：点卡账户, margin:逐仓杠杆账户，super-margin：全仓杠杆账户 |
| state | string | 是 |  |
| <list> | object | 是 |  |
| currency | string | 是 | 币种 |
| type | string | 是 | 账户类型<br>trade：交易账户，frozen：冻结账户，loan: 待还借贷本金, interest: 待还借贷利息, lock: 锁仓, bank: 储蓄 |
| balance | decimal | 是 | 账户余额 |
| debt | string | 否 | 无效字段 |
| available | string | 否 | 无效字段 |
| </list> |  | 否 |  |
| symbol | string | 是 |  |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/account/accounts/{sub-uid}"
```
