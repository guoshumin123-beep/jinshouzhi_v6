# /v2/sub-user/creation (子用户创建)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48604-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 此接口用于母用户进行子用户创建，单次最多50个 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| <userList> | object | 是 |  |
| userName | string | 是 | 子用户名，子用户身份的重要标识，要求火必平台内唯一<br>6至20位字母和数字的组合，可为纯字母；若字母和数字的组合，需以字母开头；字母不区分大小写； |
| note | string | 否 | 子用户备注，无唯一性要求<br>最多20位字符，字符类型不限 |
| </userList> |  | 否 |  |
| subAccountType | String | 否 | 子账户类型，GENERAL 普通类型(不传默认为普通类型)，CONTRACT 合约类型，GRID 合约网格类型，FIRE_BLOCK fireblock托管子账号。说明 accounts 里面不能指定子账号类型，也就是说一个批次内都是相同的子账户类型 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| userName | string | 是 | 子用户名 |
| note | string | 否 | 子用户备注（仅对有备注的子用户有效） |
| uid | long | 否 | 子用户UID（仅对创建成功的子用户有效） |
| spotAccountId | string | 否 | 现货账户ID，用于现货下单交易。如未返回，请通过/v1/account/accounts查询。 |
| errCode | string | 否 | 创建失败错误码（仅对创建失败的子用户有效） |
| errMessage | string | 否 | 创建失败错误原因（仅对创建失败的子用户有效） |
| </data> |  | 否 |  |

## 请求示例
```http
{
"userList":[
{
"userName":"test123",
"note":"huobi"
},
{
"userName":"test456",
"note":"huobitwo"
}
]
}
```

```json
{
         "code":200,
         "data":[

         "note":"HTXtwo",
```
