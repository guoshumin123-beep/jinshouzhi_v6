# /v2/sub-user/query-deposit (子用户充币记录查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48be7-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 接口描述 | 此节点用于母用户查询子用户充值记录，限母用户可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUid | long | 是 | 子用户UID，限填1个 |
| currency | string | 否 | 币种，缺省值所有币种 |
| startTime | long | 否 | 远点时间，以createTime进行检索，取值范围及缺省值见注1 |
| endTime | long | 否 | 近点时间，以createTime进行检索，取值范围及缺省值见注2 |
| sort | string | 否 | 检索方向，asc 由远及近, desc 由近及远，缺省值desc |
| limit | int | 否 | 单页最大返回条目数量 [1-500] （缺省值100） |
| fromId | long | 否 | 起始充币订单ID，仅在下页查询时有效见注3 |

**请求参数说明**：<br/>startTime取值范围：[(endTime-30天),endTime]<br/>startTime缺省值：(endTime-30天)<br/><br/>备注2：<br/>endTime取值范围：不限<br/>endTime缺省值：当前时间<br/><br/>备注3：<br/>仅当用户请求查询的时间范围内的数据条目超出单页限制（由“limit“字段设定）时，服务器才返回”nextId“字段。用户收到服务器返回的”nextId“后–<br/>1）须知晓后续仍有数据未能在本页返回；<br/>2）如需继续查询下页数据，应再次请求查询并将服务器返回的“nextId”作为“fromId“，其它请求参数不变。<br/>3）作为数据库记录ID，“nextId”和“fromId”除了用来翻页查询外，无其它业务含义。<br/>

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| id | long | 是 | 充币订单id |
| currency | string | 是 | 币种 |
| txHash | string | 是 | 交易哈希 |
| chain | string | 是 | 链名称 |
| amount | bigdecimal | 是 | 个数 |
| address | string | 是 | 地址 |
| addressTag | string | 是 | 地址标签 |
| state | string | 是 | 状态<br>unknown：状态未知，confirming：确认中，confirmed：已确认，safe：已完成，orphan：待确认 |
| createTime | long | 是 | 发起时间 |
| updateTime | long | 是 | 最后更新时间 |
| </data> |  | 否 |  |
| nextId | long | 否 | 下页起始编号（充币订单ID，仅在查询结果需要分页返回时，包含此字段） |

```http
curl"https://api.huobi.pro/v2/sub-user/query-deposit?subUid=xxxx&currency=xxx"
```
