# /v2/sub-user/management (冻结/解冻子用户)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48a6e-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 20次/2s |
| 接口描述 | 此接口用于母用户对其下一个子用户进行冻结和解冻操作 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUid | long | 是 | 子用户的UID |
| action | string | 是 | 操作类型<br>lock(冻结)，unlock(解冻) |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| <data> | object | 是 |  |
| subUid | long | 是 | 子用户UID |
| userState | string | 是 | 子用户状态<br>lock(已冻结)，normal(正常) |
| </data> |  | 否 |  |

## 请求示例
```http
{
"subUid":178211,
"action":"lock"
}
```

## 响应示例
```json
{
"code":200,
"data":{
"subUid":245686628,
"userState":"lock"
},
"ok":true
}
```
