# /v2/sub-user/user-state (获取特定子用户的用户状态)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48fe7-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 接口描述 | 母用户通过此接口可获取特定子用户的用户状态 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUid | long | 是 | 子用户UID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| uid | long | 是 | 子用户UID |
| userState | string | 是 | 子用户状态<br>lock, normal |
| </data> | object | 是 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v2/sub-user/user-state?subUid=xxxx"
```

## 响应示例
```json
{
"code":200,
"data":{
"uid":132208121,
"userState":"normal"
}
}
```
