# /v2/sub-user/tradable-market (设置子用户交易权限)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48cdc-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 此接口用于母用户批量设置子用户的交易权限。子用户的现货交易权限默认开通无须设置。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUids | string | 是 | 子用户UID列表（支持多填，最多50个，逗号分隔） |
| accountType | string | 是 | 账户类型<br>isolated-margin,cross-margin |
| activation | string | 是 | 账户激活状态<br>activated,deactivated |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| subUid | string | 是 | 子用户UID |
| accountType | string | 是 | 账户类型<br>isolated-margin,cross-margin |
| activation | string | 是 | 账户激活状态<br>activated,deactivated |
| errCode | int | 否 | 请求被拒错误码（仅在设置该subUid市场准入权限错误时返回） |
| errMessage | string | 否 | 请求被拒错误消息（仅在设置该subUid市场准入权限错误时返回） |
| </data> |  | 否 |  |

## 请求示例
```http
{
"subUids":"178211",
"accountType":"isolated-margin",
"activation":"activated"
}
```

## 响应示例
```json
{
"code":200,
"data":[
{
"subUid":"12345678",
"accountType":"isolated-margin",
"activation":"activated"
},
{
"subUid":"123456781",
"accountType":"isolated-margin",
"errCode":1002,
"errMessage":"forbidden"
}
],
"ok":true
}
```
