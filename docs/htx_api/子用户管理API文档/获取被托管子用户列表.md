# /v2/sub-user/entrust-user-list (获取被托管子用户列表)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-194fe423413

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | X/2s |
| 接口描述 | 此接口用于交易员查询当前被托管的子账户列表。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| fromId | long | 否 | 查询起始编号（仅对翻页查询有效） |
| limit | long | 否 | 默认20，最多不超过50 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 是 | 错误描述（如有）<br>ok , "error" |
| <data> | object | 是 |  |
| list |  | 否 |  |
| uid | long | 是 | 子用户UID |
| subUserName | string | 是 | 子账户用户名 |
| </data> |  | 否 | 查询id，可作为下一次查询请求的from_id字段 |
| nextId | long | 是 | 下页查询起始编号（仅在存在下页数据时返回） |
