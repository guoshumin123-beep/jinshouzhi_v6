# /v1/subuser/aggregate-balance (子用户余额（汇总）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec45ca5-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/2s |
| 接口描述 | 母用户查询其下所有子用户的各币种汇总余额 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

**请求参数说明**：<br/>此接口不接受任何参数。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态<br>"OK" or "Error" |
| <data> | list | 是 |  |
| currency | string | 是 | 币种 |
| type | string | 是 | 账户类型<br>spot：现货账户，point：点卡账户, margin:逐仓杠杆账户，super-margin：全仓杠杆账户 |
| balance | string | 是 | 账户余额（可用余额和冻结余额的总和） |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/subuser/aggregate-balance"
```

## 响应示例
```json
{
"status":"ok",
"data":[
{
"currency":"hbpoint",
"balance":"10",
"type":"point"
},
{
"currency":"ada",
"balance":"0",
"type":"spot"
},
{

"balance":"8.08559165",
"type":"spot"
}
]
}
```
