# /v1/subuser/transfer (资产划转（母子用户之间）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec45d8e-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/2s |
| 接口描述 | 母用户执行母子用户之间的划转 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| sub-uid | long | 是 | 子用户uid |
| currency | string | 是 | 币种，即btc, ltc, bch, eth, etc ... |
| amount | decimal | 是 | 划转金额 |
| client-order-id | string | 否 | 用户自编订单号（幂等使用，长度10个字符） |
| type | string | 是 | 划转类型<br>master-transfer-in（子用户划转给母用户虚拟币）/ master-transfer-out （母用户划转给子用户虚拟币）/master-point-transfer-in （子用户划转给母用户点卡）/master-point-transfer-out（母用户划转给子用户点卡） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | int | 是 | 划转订单id |
| status | string | 是 | 状态<br>"ok" or "error" |

## 请求示例
```http
{
"sub-uid":178211,
"currency":"usdt",
"amount":178211,
"client-order-id":"178211",
"type":"master-transfer-in"
}
```

## 响应示例
```json
{
"data":123456,
"status":"ok"
}
```
