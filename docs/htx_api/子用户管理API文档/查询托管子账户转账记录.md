# /v2/sub-user/managed-transfer-history (查询托管子账户转账记录)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-195600bd166

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | X/2s |
| 接口描述 | 此接口用于交易员查询当前被托管子账户的转账记录 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| uid | long | 否 | 子用户UID,若为空则默认查询该交易员名下所有被托管的子账户 |
| currency | string | 否 | 币种，即btc, ltc, bch, eth, etc ... |
| type | string | 否 | 划转类型 0：母账户转子账户 1：子账户转母账户 |
| startTime | long | 否 | 查询开始时间, 时间格式UTC time in millisecond。 以订单成交时间进行查询<br>取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近120天。 |
| endTime | long | 否 | 查询结束时间, 时间格式UTC time in millisecond。 以订单成交时间进行查询<br>取值范围 [(present-120d), present] ，查询窗口最大为48小时，窗口平移范围为最近120天。 |
| from | string | 否 | 查询起始 ID<br>如果是向后查询，则赋值为上一次查询结果中得到的最后一条id（不是trade-id） ；如果是向前查询，则赋值为上一次查询结果中得到的第一条id（不是trade-id） |
| direct | string | 否 | 查询方向<br>prev 向前；next 向后 |
| size | string | 是 | 查询记录大小<br>[1-100] |
