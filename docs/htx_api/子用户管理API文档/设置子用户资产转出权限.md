# /v2/sub-user/transferability (设置子用户资产转出权限)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48d9c-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 此接口用于母用户批量设置子用户的资产转出权限。子用户的资金转出权限包括：-由子用户现货（spot）账户转出至同一母用户下另一子用户的现货（spot）账户；-由子用户现货（spot）账户转出至母用户现货（spot）账户（无须设置，默认开通）。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUids | string | 是 | 子用户UID列表（支持多填，最多50个，逗号分隔） |
| accountType | string | 否 | 账户类型（如不填，缺省值spot） |
| transferrable | bool | 是 | 可划转权限<br>true,false |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| subUid | long | 是 | 子用户UID |
| accountType | string | 是 | 账户类型<br>spot |
| transferrable | bool | 是 | 可划转权限<br>true,false |
| errCode | int | 否 | 请求被拒错误码（仅在设置该subUid市场准入权限错误时返回） |
| errMessage | string | 否 | 请求被拒错误消息（仅在设置该subUid市场准入权限错误时返回） |
| </data> |  | 否 |  |

## 请求示例
```http
{
"subUids":"178211",
"accountType":"spot",
"transferrable":true
}
```
