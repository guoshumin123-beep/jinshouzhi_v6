# /v2/sub-user/deposit-address (子用户充币地址查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec48933-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 接口描述 | 此节点用于母用户查询子用户特定币种（IOTA除外）在其所在区块链中的充币地址，限母用户可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUid | long | 是 | 子用户UID<br>限填1个 |
| currency | string | 是 | 币种<br>btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys) |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| currency | string | 是 | 币种 |
| address | string | 是 | 充币地址 |
| addressTag | string | 是 | 充币地址标签 |
| chain | string | 是 | 链名称 |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v2/sub-user/deposit-address?subUid=xxxx&currency=xxx"
```
