# /v2/sub-user/deduct-mode (设置子用户手续费抵扣模式)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec487e5-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 此接口用于设置子用户手续费抵扣模式（子用户抵扣或母用户抵扣） |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUids | long | 是 | 子用户UID列表（支持多填，最多50个，逗号分隔） |
| deductMode | string | 是 | 抵扣模式，母账户抵扣：master 子账户抵扣：sub |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ode | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| subUid | string | 是 | 子用户UID |
| deductMode | string | 是 | 抵扣模式 |
| errCode | string | 否 | 错误码 |
| errMessage | string | 否 | 错误信息 |
| </data> |  | 否 |  |

## 请求示例
```http
{
"subUids":178211,
"deductMode":"master"
}
```

## 响应示例
```json
{
"code":200,
"data":[
{
"subUid":"158069153",
"deductMode":"master"
},
{
"subUid":"1461901631",
"deductMode":null,
"errCode":1002,
"errMessage":"forbidden"
}
],
"ok":true
}
```
