# market.$symbol.bbo (买一卖一逐笔行情)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec496d3-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | 当买一价、买一量、卖一价、卖一量，其中任一数据发生变化时，此主题推送逐笔更新。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.huobi.pro/ws` |
| 线上环境（aws客户首选） | `wss://api-aws.huobi.pro/ws` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | Array | 是 | 交易代码<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{
  "sub": ["market.btcusdt.bbo","market.ethusdt.bbo","market.htxusdt.bbo"],
  "id": "id1"
}
```

## 响应示例
```json
{
"id":"id1",
"status":"ok",
"subbed":"market.btcusdt.bbo",
"ts":1489474081631
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ch | string | 否 | 数据所属的 channel，格式：market.$symbol.kline.$period |
| ts | long | 否 | 系统响应时间 |
| <data> | object | 否 |  |
| symbol | string | 否 | 交易代码 |
| quoteTime | long | 否 | 盘口更新时间 |
| bid | float | 否 | 买一价 |
| bidSize | float | 否 | 买一量 |
| ask | float | 否 | 卖一价 |
| askSize | float | 否 | 卖一量 |
| seqId | int | 否 | 消息序号 |
| </data> |  | 否 |  |

## 推送示例
```json
{
"ch":"market.btcusdt.bbo",
"ts":1630994555540,
"tick":{
"seqId":137005210233,
"ask":52665.02,
"askSize":1.502181,
"bid":52665.01,
"bidSize":0.178567,
"quoteTime":1630994555539,
"symbol":"btcusdt"
}
}
```

## 取消订阅示例
```json
{
  "unsub": "market.btcusdt.bbo",
  "id": "id1"
}
```
