# market.$symbol.detail (市场概要)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4994b-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | 此主题提供24小时内最新市场概要快照。快照频率不超过每秒10次。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.huobi.pro/ws` |
| 线上环境（aws客户首选） | `wss://api-aws.huobi.pro/ws` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | Array | 是 | 交易代码<br>btcusdt, ethbtc...等 |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{
  "sub": ["market.btcusdt.depth.step0","market.ethusdt.depth.step0","market.trxusdt.depth.step0"],
  "id": "id1"
}
```

## 响应示例
```json
{
"id":"id1",
"status":"ok",
"subbed":"market.btcusdt.detail",
"ts":1489474081631
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ch | string | 否 | 数据所属的 channel，格式：market.btcusdt.detail |
| ts | long | 否 | 系统响应时间 |
| <tick> | object | 否 |  |
| id | integer | 否 | unix时间，同时作为消息ID |
| amount | float | 否 | 24小时成交量 |
| count | integer | 否 | 24小时成交笔数 |
| open | float | 否 | 24小时开盘价 |
| close | float | 否 | 最新价 |
| low | float | 否 | 24小时最低价 |
| high | float | 否 | 24小时最高价 |
| vol | float | 否 | 24小时成交额 |
| version | long | 否 | 版本号 |
| </tick> |  | 否 |  |

## 推送示例
```json
{
"ch":"market.btcusdt.detail",
"ts":1630998026649,
"tick":{
"id":273956868110,
"low":51000,
"high":52924.14,
"open":51823.62,
"close":52379.99,
"vol":727676440.200527,
"amount":13991.028076056185,
"version":273956868110,
"count":471348
}
}
```

## 取消订阅示例
```json
{
  "unsub": "market.btcusdt.detail",
  "id": "id1"
}
```
