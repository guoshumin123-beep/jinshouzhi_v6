# market.$symbol.trade.detail (成交明细)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec49dfb-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | 此主题提供市场最新成交逐笔明细。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.huobi.pro/ws` |
| 线上环境（aws客户首选） | `wss://api-aws.huobi.pro/ws` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | Array | 是 | 交易代码<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| cid | string | 否 | 表示本次请求id |

## 请求示例
```json
{
  "sub":[ "market.btcusdt.trade.detail", "market.ethusdt.trade.detail", "market.htxusdt.trade.detail"],
  "id": "id1"
}
```

## 响应示例
```json
{
"id":"id1",
"status":"ok",
"subbed":"market.btcusdt.trade.detail",
"ts":1489474081631
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ch | string | 否 | 数据所属的 channel，格式：market.$symbol.trade.detail |
| ts | long | 否 | 系统响应时间 |
| <tick> | object | 否 |  |
| id | long | 否 | 全局成交ID |
| ts | long | 否 | 最新成交时间 |
| <data> | object | 否 |  |
| id | integer | 否 | 唯一成交ID（将被废弃） |
| tradeId | long | 否 | 唯一成交ID（NEW） |
| amount | float | 否 | 成交量（买或卖一方） |
| price | float | 否 | 成交价 |
| ts | long | 否 | 成交时间 (UNIX epoch time in millisecond) |
| direction | string | 否 | 成交主动方 (taker的订单方向) : 'buy' or 'sell' |
| </data> |  | 否 |  |
| </tick> |  | 否 |  |

## 推送示例
```json
{
"ch":"market.btcusdt.trade.detail",
"ts":1630994963175,
"tick":{
"id":137005445109,
"ts":1630994963173,
"data":[
{
"id":137005445109359286410323766,
"ts":1630994963173,
"tradeId":102523573486,
"amount":0.006754,
"price":52648.62,
"direction":"buy"
}
]
}
}
```

## 取消订阅示例
```json
{
  "unsub": "market.btcusdt.trade.detail",
  "id": "id1"
}
```
