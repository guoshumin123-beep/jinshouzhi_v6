# 介绍

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=5485

此 API 只能用于现货 （`SPOT`） 交易所。

接入URL

订单接入URL：`tcp+tls：//fix-order.huobi.pro：9000`

`支持功能：`支持下单，取消订单。

行情接入URL：`tcp+tls：//fix-market.huobi.pro：9000`

`支持功能：`支持行情推送。

Schema xml: [https://github.com/huobiapi/huobi_fix/blob/main/FIX44.xml](https://github.com/huobiapi/huobi_fix/blob/main/FIX44.xml)

限制

每个连接发送到交易所的消息数量 的限制，200/s；共享订单的限频。违反限制时，Reject `` 消息会被发送给用户。

每个账户建立的 TCP 连接数量 的限制，10个。违反限制时， Logout `` 消息会被发送给用户，并断联。

响应模式

FIX API 允许单个账户的多个并发会话。 默认情况下，所有会话将接收该账户的所有成功 ExecutionReport`` 消息。这些消息也包括那些来自其他 FIX 会话和非 FIX API 下单的响应消息。

Header

出现在每条消息的开头。

| Tag | 名称 | 类型 | 是否必须 | 描述 |
|---|---|---|---|---|
| 8 | BeginString | String | Y | 始终为 FIX.4.4。必须是消息的第一个字段。 |
| 9 | BodyLength | Int | Y | 消息长度（以字节为单位）。必须是消息的第二个字段。 |
| 35 | MsgType | String | Y | 必须是消息的第三个字段。 |
| 49 | SenderCompID | String | Y | 连接唯一标记，字母数字，字母数字组合，10-32个字符，建议uuid |
| 56 | TargetCompID | String | Y | 在客户端的消息中必须设置为spot。 |
| 34 | MsgSeqNum | Int | Y | 整数消息序列号。间隙的值将被拒绝。 |
| 52 | SendingTime | UTCTimestamp | Y | 消息传输时间（始终以 UTC 表示YYYYMMDD-HH:MM:SS.sss）。 |

Trailer

出现在每条消息的末尾。

| Tag | 名称 | 类型 | 是否必须 | 描述 |
|---|---|---|---|---|
| 10 | CheckSum | String | Y | 校验值 |
