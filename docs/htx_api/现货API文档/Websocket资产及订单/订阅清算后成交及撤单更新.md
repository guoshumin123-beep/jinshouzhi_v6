# trade.clearing#${symbol}#${mode} (订阅清算后成交及撤单更新)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4a03c-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | - |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | 仅当用户订单成交或撤销时推送。其中，订单成交为逐笔推送，如一张taker订单同时与多张maker订单成交，该接口将推送逐笔更新。但用户收到的这几笔成交消息的次序，有可能与实际的成交次序不完全一致。另外，如果一张订单的成交及撤销几乎同时发生，例如IOC订单成交后剩余部分被自动撤销，用户可能会先收到撤单推送，再收到成交推送。<br><br>如用户需要获取依次更新的订单推送，建议订阅另一频道orders#${symbol}。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `wss://api.huobi.pro/ws/v2` |
| 线上环境（aws客户首选） | `wss://api-aws.huobi.pro/ws/v2` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | string<br>如 btcusdt 支持通配符 * |
| mode | string | 否 | 模式<br>0： 仅在订单成交时推送； 1：在订单成交、撤销时均推送 |

## 请求示例
```json
{
"action":"sub",
"ch":"trade.clearing#btcusdt#0"
}
```

## 响应示例
```json
{
"action":"sub",
"code":200,
"ch":"trade.clearing#btcusdt#0",
"data":{}
}
```

## 推送数据
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| eventType | string | 否 | 事件类型（trade） |
| symbol | string | 否 | 交易代码 |
| orderId | long | 否 | 订单ID |
| tradePrice | string | 否 | 成交价 |
| tradeVolume | string | 否 | 成交量 |
| orderSide | string | 否 | 订单方向，有效值： buy, sell |
| orderType | string | 否 | 订单类型，有效值： buy-market, sell-market,buy-limit,sell-limit,buy-ioc,sell-ioc,buy-limit-maker,sell-limit-maker,buy-stop-limit,sell-stop-limit,buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| aggressor | bool | 否 | 是否交易主动方，有效值： true, false |
| tradeId | long | 否 | 交易ID |
| tradeTime | long | 否 | 成交时间，unix time in millisecond |
| transactFee | string | 否 | 交易手续费（正值）或交易手续费返佣（负值） |
| feeCurrency | string | 否 | 交易手续费或交易手续费返佣币种（买单的交易手续费币种为基础币种，卖单的交易手续费币种为计价币种；买单的交易手续费返佣币种为计价币种，卖单的交易手续费返佣币种为基础币种） |
| feeDeduct | string | 否 | 交易手续费抵扣 |
| feeDeductType | string | 否 | 交易手续费抵扣类型，有效值： ht, point |
| accountId | long | 否 | 账户编号 |
| source | string | 否 | 订单来源 |
| orderPrice | string | 否 | 订单价格 （市价单无此字段） |
| orderSize | string | 否 | 订单数量（市价买单无此字段） |
| orderValue | string | 否 | 订单金额（仅市价买单有此字段） |
| clientOrderId | string | 否 | 用户自编订单号 |
| stopPrice | string | 否 | 订单触发价（仅止盈止损订单有此字段） |
| operator | string | 否 | 订单触发方向（仅止盈止损订单有此字段） |
| orderCreateTime | long | 否 | 订单创建时间 |
| orderStatus | string | 否 | 订单状态，有效值：filled, partial-filled |
|  time-in-force | string | 否 | 交易时效性<br>rpi : rpi订单 <br>gtc: 普通订单<br>ioc: ioc订单<br>fok: fok订单 |
