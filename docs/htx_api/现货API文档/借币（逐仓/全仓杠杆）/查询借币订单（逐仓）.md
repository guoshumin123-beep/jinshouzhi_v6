# /v1/margin/loan-orders (查询借币订单（逐仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43693-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 100次/2s |
| 接口描述 | 此接口基于指定搜索条件返回借币订单。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| start-date | string | 否 | 查询开始日期, 日期格式yyyy-mm-dd |
| end-date | string | 否 | 查询结束日期, 日期格式yyyy-mm-dd |
| states | string | 否 | 状态列表，可以支持多个状态，用逗号分隔<br>created 未放款，accrual 已放款，cleared 已还清，invalid 异常，failed 借贷失败 |
| from | string | 否 | 查询起始 ID |
| direct | string | 否 | 查询方向<br>prev 向前，时间（或 ID）正序；next 向后，时间（或 ID）倒序） |
| size | string | 否 | 查询记录大小<br>[1, 100] |
| sub-uid | int | 否 | 子用户编号（母用户查询子用户借币订单时，此字段必填） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| id | long | 是 | 订单号 |
| user-id | long | 是 | 用户ID |
| account-id | long | 是 | 账户ID |
| symbol | string | 是 | 交易对 |
| currency | string | 是 | 币种 |
| loan-amount | string | 是 | 借币本金总额 |
| loan-balance | string | 是 | 未还本金 |
| interest-rate | string | 是 | 币息率 |
| interest-amount | string | 是 | 币息总额 |
| interest-balance | string | 是 | 未还币息 |
| created-at | long | 是 | 借币发起时间 |
| accrued-at | long | 是 | 最近一次计息时间 |
| state | string | 是 | 订单状态<br>created 未放款，accrual 已放款，cleared 已还清，invalid 异常，failed 借贷失败 |
| paid-point | string | 是 | 已支付点卡金额（用于还息） |
| paid-coin | string | 是 | 已支付原币金额（用于还息） |
| deduct-rate | string | 是 | 抵扣率（用于还息） |
| deduct-currency | string | 是 | 抵扣币种（用于还息） |
| deduct-amount | string | 是 | 抵扣金额（用于还息） |
| updated-at | long | 是 | 更新时间 |
| hour-interest-rate | string | 是 | 时息率 |
| day-interest-rate | string | 是 | 日息率 |
| </data> |  | 否 |  |
