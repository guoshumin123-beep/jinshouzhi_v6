# /v1/cross-margin/loan-orders (查询借币订单（全仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec419f5-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/2s |
| 接口描述 | 此接口基于指定搜索条件返回借币订单。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| start-date | string | 否 | 查询开始日期, 日期格式yyyy-mm-dd |
| end-date | string | 否 | 查询结束日期, 日期格式yyyy-mm-dd |
| currency | string | 否 | 币种 |
| state | string | 否 | 状态<br>created 未放款，accrual 已放款，cleared 已还清，invalid 异常 |
| from | string | 否 | 查询起始 ID |
| direct | string | 否 | 查询方向<br>prev 向前，时间（或 ID）正序；next 向后，时间（或 ID）倒序） |
| size | string | 否 | 查询记录大小<br>[10-100] |
| sub-uid | long | 否 | 子用户UID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| id | long | 是 | 订单号 |
| user-id | long | 是 | 用户ID |
| account-id | long | 是 | 账户ID |
| currency | string | 是 | 币种 |
| loan-amount | string | 是 | 借币本金总额 |
| loan-balance | string | 是 | 未还本金 |
| interest-amount | string | 是 | 币息总额 |
| interest-balance | string | 是 | 未还币息 |
| filled-points | string | 是 | 点卡抵扣数量 |
| filled-ht | string | 是 | HT抵扣数量 |
| created-at | long | 是 | 借币发起时间 |
| accrued-at | long | 是 | 最近一次计息时间 |
| state | string | 是 | 订单状态<br>created 未放款，accrual 已放款，cleared 已还清，invalid 异常 |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/cross-margin/loan-orders?start-date=xxxx&end-date=xxxxxx&currency=xxxxxx&state=created&from=xxxx&direct=next&size=100&sub-uid=xxxxxx"
```
