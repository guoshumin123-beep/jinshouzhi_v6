# /v2/account/repayment (归还借币（全仓逐仓通用）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46300-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/秒 |
| 接口描述 | 还币顺序为，（如不指定transactId）先借先还，利息先还；如指定transactId时，currency参数不做校验。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| accountId | string | 是 | 还币账户ID |
| currency | string | 是 | 还币币种 |
| amount | string | 是 | 还币金额 |
| transactId | string | 否 | 原始借币交易ID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | array | 是 |  |
| repayId | string | 是 | 还币交易ID |
| repayTime | long | 是 | 还币交易时间（unix time in millisecond） |
| </data> |  | 否 |  |

**响应参数说明**：<br/>返回relayId不意味着该还币100%成功，用户须在还币后通过查询还币交易记录确认该还币状态。<br/>

## 请求示例
```http
{
"accountid":"1266826",
"currency":"btc",
"amount":"0.00800334",
"transactId":"437"
}
```

## 响应示例
```json
{
"code":200,
"Data":[
{
"repayId":1174424,
"repayTime":1600747722018
}
]
}
```
