# /v1/cross-margin/accounts/balance (借币账户详情（全仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4163f-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/2s |
| 接口描述 | 此接口返回借币账户详情。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| sub-uid | long | 否 | 子用户UID |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| id | integer | 是 | Account ID 账户编号 |
| type | integer | 是 | 账户类型：cross-margin |
| state | string | 是 | 账户状态：working 正常,fl-sys 系统自动爆仓,fl-end 爆仓结束,fl-negative 穿仓 |
| risk-rate | string | 是 | 风险率 |
| acct-balance-sum | string | 是 | 总持有usdt折合 |
| debt-balance-sum | string | 是 | 总负债usdt折合 |
| <list> | array | 是 | 借币账户详情列表 |
| currency | string | 是 | 币种 |
| type | string | 是 | 账户类型，trade: 交易余额, frozen: 冻结余额, loan: 待还借贷本金, interest: 待还借贷利息, ,transfer-out-available 可划转额, loan-available 可借额 |
| balance | string | 是 | 余额，负数表示应还金额。transfer-out-available的账户余额如果为-1，代表该币种可全部转出。 |
| </list> |  | 否 |  |
| </data> |  | 否 |  |

```http

```
