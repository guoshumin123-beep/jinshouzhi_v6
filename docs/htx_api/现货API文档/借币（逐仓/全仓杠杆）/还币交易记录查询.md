# /v2/account/repayment (还币交易记录查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec463e6-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/秒 |
| 接口描述 | 子用户可以调用<br><br>按repayTime检索 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| repayId | string | 否 | 还币交易ID |
| accountId | string | 否 | 账户ID（缺省值：所有账户） |
| currency | string | 否 | 借入/借出币种（缺省值：所有币种） |
| startTime | long | 否 | 远点时间（unix time in millisecond；取值范围：[(endTime - x天), endTime]；缺省值：(endTime - x天)） |
| endTime | long | 否 | 近点时间（unix time in millisecond；取值范围：[(当前时间 - y天), 当前时间]；缺省值：当前时间） |
| sort | string | 否 | 检索方向（有效值：asc 由远及近, desc 由近及远；缺省值：desc） |
| limit | integer | 否 | 单页最大返回条目数量（取值范围：[1-100]；缺省值：50） |
| fromId | long | 否 | 查询起始编号（仅对翻页查询有效） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | array | 是 | 按sort指定顺序排列 |
| repayId | string | 是 | 还币交易ID |
| repayTime | long | 是 | 还币交易时间（unix time in millisecond） |
| accountId | string | 是 | 还币账户ID |
| currency | string | 是 | 还币币种 |
| repaidAmount | string | 是 | 已还币金额 |
| <transactIds> | object | 是 | 该笔还币所涉及的原始借币交易ID列表（按还币优先顺序排列） |
| transactId | long | 是 | 原始借币交易ID |
| repaidPrincipal | string | 是 | 该笔还币交易已还本金 |
| repaidInterest | string | 是 | 该笔还币交易已还利息 |
| paidHt | string | 是 | 该笔还币交易已支付HT金额 |
| paidPoint | string | 是 | 该笔还币交易已支付点卡金额 |
| </transactIds> |  | 否 |  |
| </data> |  | 否 |  |
| nextId | long | 否 | 下页查询起始编号（仅在存在下页数据时返回） |

## 请求示例
```http
curl"https://api.huobi.pro/v2/account/repayment?repayId=xxxx&accountId=xxx&currency=xxx"
```
