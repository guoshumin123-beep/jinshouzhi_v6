# /v1/margin/orders/{order-id}/repay (归还借币（逐仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43a58-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/2s |
| 接口描述 | 此接口用于归还借币. |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order-id | string | 是 | 借币订单 ID，写在 url path 中 |
| amount | string | 是 | 归还币种数量 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | integer | 否 | Margin order id |

## 请求示例
```http
{
"amount":"1.0"
}
```

## 响应示例
```json
{
"data":1000
}
```
