# /v1/dw/transfer-out/margin (资产划出（逐仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec427c6-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/2s |
| 接口描述 | 此接口用于现货账户与逐仓杠杆账户的资产互转。<br><br>从现货账户划转至逐仓杠杆账户transfer-in，从逐仓杠杆账户划转至现货账户transfer-out |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对, e.g. btcusdt, ethbtc |
| currency | string | 是 | 币种 |
| amount | string | 是 | 划转数量 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | integer | 否 | Transfer id |
| status | string | 否 | 状态 |
| code | integer | 否 | 状态码 |

## 请求示例
```http
{
"symbol":"ethusdt",
"currency":"eth",
"amount":"1.0"
}
```

## 响应示例
```json
{
"status":"ok",
"data":46971504,
"code":200
}
```
