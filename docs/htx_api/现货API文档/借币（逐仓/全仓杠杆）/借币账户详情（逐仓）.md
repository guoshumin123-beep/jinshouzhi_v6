# /v1/margin/accounts/balance (借币账户详情（逐仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec432bf-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 100次/2s |
| 接口描述 | 此接口返回借币账户详情。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 否 | 交易对，作为get参数。如果不传则不返回可转余额(transfer-out-available)和可借余额(loan-available) |
| sub-uid | int | 否 | 子用户编号（母用户查询子用户借币详情时，此字段必填） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| <data> | object | 是 |  |
| id | int | 是 |  |
| type | string | 是 |  |
| fl-type | string | 是 | safe,sell,buy |
| symbol | string | 是 | 交易对 |
| state | string | 是 | 账户状态，working 正常,fl-sys 系统自动爆仓,fl-mgt 手动爆仓,fl-end 爆仓结束 |
| risk-rate | string | 是 | 风险率 |
| fl-price | string | 是 | 爆仓价 |
| <list> | array | 是 | 借币账户详情列表 |
| currency | string | 是 | 币种 |
| type | string | 是 | 类型，trade: 交易余额, frozen: 冻结余额, loan: 待还借贷本金, interest: 待还借贷利息, ,transfer-out-available 可划转额, loan-available 可借额 |
| balance | string | 是 | 余额，负数表示应还金额。transfer-out-available的余额如果为-1，代表该币种可全部转出。 |
| </list> |  | 否 |  |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/margin/accounts/balance?symbol=xxxx&sub-uid=xxxx"
```
