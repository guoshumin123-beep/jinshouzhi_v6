# /v1/cross-margin/orders (申请借币（全仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec41b5d-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/2s |
| 接口描述 | 此接口用于申请借币. |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | string | 是 | 币种 |
| amount | string | 是 | 借币数量（精度：3位小数） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |
| data | integer | 否 | Margin order id |

## 请求示例
```http
{
"currency":"eth",
"amount":"1.0"
}
```

## 响应示例
```json
{
"status":"ok",
"data":1000
}
```
