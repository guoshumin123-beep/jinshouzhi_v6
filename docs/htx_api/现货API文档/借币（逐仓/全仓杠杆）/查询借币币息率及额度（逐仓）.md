# /v1/margin/loan-info (查询借币币息率及额度（逐仓）)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43494-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 此接口返回用户级别的借币币息率及借币额度。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbols | string | 否 | 交易代码 (可多选，以逗号分隔) |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |
| <data> | object | 否 |  |
| symbol | string | 否 | 交易代码 |
| <currencies> | object | 否 |  |
| currency | string | 否 | 币种 |
| interest-rate | string | 否 | 基础日币息率 |
| min-loan-amt | string | 否 | 最小允许借币金额 |
| max-loan-amt | string | 否 | 最大允许借币金额 |
| loanable-amt | string | 否 | 最大可借金额 |
| actual-rate | string | 否 | 抵扣后的实际借币币息率，如不适用抵扣或未启用抵扣，返回基础日币息率 |
| </currencies> |  | 否 |  |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/margin/loan-info?symbol=all"
```
