# /market/trade (最近市场成交记录)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec40568-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | - |
| 限频 | 4,500 5 minutes |
| 接口描述 | 此接口返回指定交易对最新的一个交易记录。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 要查询的交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 请求处理结果 "ok","error" |
| ch | string | 否 | 数据所属的 channel，格式：market.$symbol.trade.detail |
| ts | long | 否 | 响应生成时间点，单位：毫秒 |
| <tick> | object | 否 |  |
| id | long | 否 | 全局成交ID |
| ts | long | 否 | 最新成交时间 |
| <data> | object | 否 |  |
| id | integer | 否 | 唯一交易id（将被废弃） |
| trade-id | integer | 否 | 唯一成交ID（NEW） |
| amount | float | 否 | 以基础币种为单位的交易量 |
| price | float | 否 | 以报价币种为单位的成交价格 |
| ts | integer | 否 | 调整为新加坡时间的时间戳，单位毫秒 |
| direction | string | 否 | 交易方向：“buy” 或 “sell”, “buy” 即买，“sell” 即卖 |
| is-rpi-trade | boolean | 否 | 是否为RPI交易 |
| </data> |  | 否 |  |
| </tick> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/market/trade?symbol=btcusdt"
```
