# /market/depth (市场深度数据)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec3f447-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | - |
| 限频 | 4,000 5 minutes |
| 接口描述 | 此接口返回指定交易对的当前市场深度数据。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| depth | integer | 否 | 返回深度的数量<br>5，10，20，30 |
| type | string | 是 | 深度的价格聚合度，具体说明见下方<br>step0：无聚合，默认返回150档数据<br>step1：聚合度为报价精度*10，默认返回20档数据<br>step2：聚合度为报价精度*100，默认返回20档数据<br>step3：聚合度为报价精度*1000 ，默认返回20档数据<br>step4：聚合度为报价精度*5000，默认返回20档数据<br>step5：聚合度为报价精度*100000, 默认返回20档数据 |
| includeRpi | Boolean | 否 | 是否包含 RPI 订单数据。<br><br>为 true 时包含 RPI 订单数据，为false时不包含 RPI 订单数据<br>true，false |

**请求参数说明**：<br/>当type值为‘step0’时，‘depth’若不输入，则默认值为150。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 请求处理结果 "ok","error" |
| ch | string | 否 | 数据所属的 channel，格式： market.$symbol.depth.$type |
| ts | long | 否 | 响应生成时间点，单位：毫秒 |
| <tick> | object | 否 |  |
| ts | integer | 否 | 调整为新加坡时间的时间戳，单位毫秒 |
| version | integer | 否 | 内部字段 |
| bids | object | 否 | 当前的所有买单 [price, size] |
| asks | object | 否 | 当前的所有卖单 [price, size] |
| </tick> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/market/depth?symbol=btcusdt&depth=5&type=step0"
```
