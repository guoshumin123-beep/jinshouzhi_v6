# /market/fullMbp (查询完整深度)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-1934265cfd6

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 5次/s |
| 接口描述 | 查询完整的盘口深度数据，每秒更新一次，最大可支持返回5000档。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对，最大可支持返回5000档。 |
| includeRpi | Boolean | 否 | 是否包含 RPI 订单数据。<br><br>为 true 时包含 RPI 订单数据，为false时不包含 RPI 订单数据 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 请求处理结果 "ok","error" |
| ch | string | 否 | 数据所属的 channel，格式： market.$symbol.depth.$type |
| ts | long | 否 | 响应生成时间点，单位：毫秒 |
| <tick>	 | object | 否 |  |
| ts | integer	 | 否 | 调整为新加坡时间的时间戳，单位毫秒 |
| version	 | integer	 | 否 | 内部字段 |
| bids | object | 否 | 当前的所有买单 [price, size] |
| asks | object | 否 | 当前的所有卖单 [price, size] |
| </tick>	 |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/market/fullMbp?symbol=ethusdt"
```
