# /v1/order/batch-orders (批量下单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43b98-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 50次/2s |
| 接口描述 | 一个批量最多10张订单 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| [{ account-id | string | 是 | 账户 ID，取值参考 GET /v1/account/accounts。现货交易使用 ‘spot’ 账户的 account-id；逐仓杠杆交易，请使用 ‘margin’ 账户的 account-id；全仓杠杆交易，请使用 ‘super-margin’ 账户的 account-id; C2C杠杆交易，请使用borrow账户的account-id |
| symbol | string | 是 | 交易对,即btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| type | string | 是 | 订单类型，包括buy-market, sell-market, buy-limit, sell-limit, buy-ioc, sell-ioc, buy-limit-maker, sell-limit-maker（说明见下文）, buy-stop-limit, sell-stop-limit, buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| amount | string | 是 | 订单交易量（市价买单为订单交易额） |
| price | string | 否 | 订单价格（对市价单无效） |
| source | string | 否 | 现货交易填写“spot-api”，逐仓杠杆交易填写“margin-api”，全仓杠杆交易填写“super-margin-api”, C2C杠杆交易填写"c2c-margin-api" |
| client-order-id | string | 否 | 用户自编订单号，clientorderid 会做唯一性检查，有效期8小时 |
| self-match-prevent | int | 否 | 自成交 ，0：表示允许自成交; 1：表示不允许自成交 |
| stop-price | string | 否 | 止盈止损订单触发价格 |
| operator  | string | 否 | 止盈止损订单触发价运算符 gte – greater than and equal (>=), lte – less than and equal (<=) |
| ice-amount | string | 否 | 冰山单单次下单数量 |
|  time-in-force | string | 否 | rpi订单 （ type 必须为 buy-limit，sell-limit）<br>rpi |

**请求参数说明**：<br/>buy-limit-maker<br/>当“下单价格”>=“市场最低卖出价”，订单提交后，系统将拒绝接受此订单；<br/>当“下单价格”<“市场最低卖出价”，提交成功后，此订单将被系统接受。<br/>sell-limit-maker<br/>当“下单价格”<=“市场最高买入价”，订单提交后，系统将拒绝接受此订单；<br/>当“下单价格”>“市场最高买入价”，提交成功后，此订单将被系统接受。<br/>

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |
| <data> | object | 否 |  |
| order-id | long | 否 | 订单编号 |
| client-order-id | string | 否 | 用户自编订单号（如有） |
| err-code | string | 否 | 订单被拒错误码（仅对被拒订单有效） |
| err-msg | string | 否 | 订单被拒错误信息（仅对被拒订单有效） |
| </data> |  | 否 |  |

## 请求示例
```http
[
{
"account-id":"13496526",
"symbol":"adausdt",
"type":"buy-limit-maker",
"amount":"5",
"price":"1",
"source":"spot-api",
"client-order-id":"2345"
},
{
"account-id":"13496526",
"symbol":"adausdt",
"type":"buy-limit-maker",
"amount":"4",
"price":"1",
"source":"spot-api",
"client-order-id":"23456"
}
]
```
