# /v1/order/matchresults (当前和历史成交)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43e12-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 此接口基于搜索条件查询当前和历史成交记录。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string<br>          | 是 | 交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| types | string<br>          | 否 | 查询的订单类型组合，使用','分割<br>所有可能的订单类型（见本章节简介） |
| start-time | long<br>          | 否 | 查询开始时间, 时间格式UTC time in millisecond。 以订单成交时间进行查询<br>取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近120天。 |
| end-time | long<br>          | 否 | 查询结束时间, 时间格式UTC time in millisecond。 以订单成交时间进行查询<br>取值范围 [(present-120d), present] ，查询窗口最大为48小时，窗口平移范围为最近120天。 |
| from | string<br>          | 否 | 查询起始 ID<br>如果是向后查询，则赋值为上一次查询结果中得到的最后一条id（不是trade-id） ；如果是向前查询，则赋值为上一次查询结果中得到的第一条id（不是trade-id） |
| direct | string<br>          | 否 | 查询方向<br>prev 向前；next 向后 |
| size | string | 否 | 查询记录大小<br>[1-500] |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string<br>          | 是 | 状态 |
| <data> | object<br>          | 是 |  |
| created-at | long<br>          | 是 | 该成交记录创建的时间戳（略晚于成交时间） |
| filled-amount | string<br>          | 是 | 成交数量 |
| filled-fees | string<br>          | 是 | 交易手续费（正值）或交易返佣（负值）<br>当"fee-deduct-state" = "done"，则代表终态 |
| fee-currency | string<br>          | 是 | 交易手续费或交易返佣币种（买单的交易手续费币种为基础币种，卖单的交易手续费币种为计价币种；买单的交易返佣币种为计价币种，卖单的交易返佣币种为基础币种） |
| id | long<br>          | 是 | 订单成交记录 ID，无大小顺序，可作为下一次翻页查询请求的from字段 |
| match-id | long<br>          | 是 | 撮合 ID |
| order-id | long<br>          | 是 | 订单 ID |
| trade-id | integer<br>          | 是 | 唯一成交编号 |
| price | string<br>          | 是 | 成交价格 |
| source | string<br>          | 是 | 订单来源<br>"sys":"系统订单","web":"用户WEB订单","api":"用户API订单","app":"用户APP订单","fl-sys":"系统爆仓订单","fl-mgt":"手动爆仓订单","spot-stop":"计划委托现货","margin-stop":"杠杆计划委托逐仓","super-margin-stop":"杠杆计划委托全仓","grid-trading-sys":"网格下单" |
| symbol | string<br>          | 是 | 交易对 |
| type | string<br>          | 是 | 订单类型 |
| role | string<br>          | 是 | 成交角色 |
| filled-points | string<br>          | 是 | 抵扣数量（可为htx或hbpoint） |
| fee-deduct-currency | string<br>          | 是 | 抵扣类型 |
| fee-deduct-state | string<br>          | 是 | 抵扣状态<br>抵扣中：ongoing，抵扣完成：done |
|  time-in-force | string | 否 | 交易时效性<br>rpi : rpi订单 <br>gtc: 普通订单<br>ioc: ioc订单<br>fok: fok订单 |
| </data> |  | 否 |  |

**响应参数说明**：<br/>返回的主数据对象为一个对象数组，其中每一个元件代表一个交易结果。

## 请求示例
```http
curl"https://api.huobi.pro/v1/order/matchresults?symbol=btcusdi"
```
