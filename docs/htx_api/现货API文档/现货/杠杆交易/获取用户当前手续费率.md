# /v2/reference/transact-fee-rate (获取用户当前手续费率)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec47a2e-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 50 times / 2s |
| 接口描述 | Api用户查询交易对费率，一次限制最多查10个交易对，子用户的费率和母用户保持一致 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbols | string | 是 | 交易对，可多填，逗号分隔<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols）> |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 否 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 否 |  |
| symbol | string | 否 | 交易代码 |
| makerFeeRate | string | 否 | 基础费率 - 被动方，如适用交易手续费返佣，返回返佣费率（负值） |
| takerFeeRate | string | 否 | 基础费率 - 主动方 |
| actualMakerRate | string | 否 | 抵扣后费率 - 被动方，如不适用抵扣或未启用抵扣，返回基础费率；如适用交易手续费返佣，返回返佣费率（负值） |
| actualTakerRate | string | 否 | 抵扣后费率 – 主动方，如不适用抵扣或未启用抵扣，返回基础费率 |
| rpiFeeRate | string | 否 | RPI手续费率<br><br>例 “0.01” 代表 1% |
| </data> |  | 否 |  |

**响应参数说明**：<br/>-如makerFeeRate/actualMakerRate为正值，该字段意为交易手续费率；<br/>-如makerFeeRate/actualMakerRate为负值，该字段意为交易返佣费率。

## 请求示例
```http
curl"https://api.huobi.pro/v2/reference/transact-fee-rate?symbols=btcusdt"
```
