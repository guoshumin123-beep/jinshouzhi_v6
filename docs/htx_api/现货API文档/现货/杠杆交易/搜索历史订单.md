# /v1/order/orders (搜索历史订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec440d2-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 50次/2s |
| 接口描述 | 此接口基于搜索条件查询历史订单。通过API创建的订单，撤销超过2小时后无法查询。<br><br>如用户start-time和end-time两个参数都没填写，服务器将返回由近到远[now,now-48小时]内的历史订单。<br>如用户填写start-time而没填写end-time参数，服务器将返回由近到远[start-time+48小时,start-time]内的历史订单。<br>如用户没有填写start-time而填写end-time参数，服务器将返回由近到远[end-time,end-time-48小时]内的历史订单。<br>如用户start-time和end-time两个参数都填写了，服务器将返回由近到远[end-time,start-time]内的历史订单。<br>每次查询范围最大为48小时,可连续查询最近180天数据。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| types | string | 否 | 查询的订单类型组合，使用逗号分割<br>所有可能的订单类型（见本章节简介） |
| start-time | long | 否 | 查询开始时间, 时间格式UTC time in millisecond。 以订单生成时间进行查询<br>取值范围 [((end-time) – 48h), (end-time)] ，查询窗口最大为48小时，窗口平移范围为最近180天，已完全撤销的历史订单的查询窗口平移范围只有最近2小时(state="canceled") |
| end-time | long | 否 | 查询结束时间, 时间格式UTC time in millisecond。 以订单生成时间进行查询<br>取值范围 [(present-179d), present] ，查询窗口最大为48小时，窗口平移范围为最近180天，已完全撤销的历史订单的查询窗口平移范围只有最近2小时(state="canceled") |
| states | string | 是 | 查询的订单状态组合，使用','分割<br>filled（已成交），partial-canceled（部分成交撤销），canceled（已撤销） |
| from | string | 否 | 查询起始 ID<br>如果是向后查询，则赋值为上一次查询结果中得到的最后一条id ；如果是向前查询，则赋值为上一次查询结果中得到的第一条id |
| direct | string | 否 | 查询方向<br>prev 向前；next 向后 |
| size | string | 否 | 查询记录大小<br>[1-100] |
