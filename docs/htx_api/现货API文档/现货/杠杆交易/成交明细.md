# /v1/order/orders/{order-id}/matchresults (成交明细)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4445c-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 50次/2s |
| 接口描述 | 此接口返回指定订单的成交明细。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order-id | string | 是 | 订单ID，填在path中 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| created-at | long | 是 | 该成交记录创建的时间戳（略晚于成交时间） |
| filled-amount | string | 是 | 成交数量 |
| filled-fees | string | 是 | 交易手续费（正值）或交易返佣金（负值）<br>当"fee-deduct-state" = "done"，则代表终态 |
| fee-currency | string | 是 | 交易手续费或交易返佣币种（买单的交易手续费币种为基础币种，卖单的交易手续费币种为计价币种；买单的交易返佣币种为计价币种，卖单的交易返佣币种为基础币种） |
| id | long | 是 | 订单成交记录ID |
| match-id | long | 是 | 撮合ID，订单在撮合中执行的顺序ID |
| order-id | long | 是 | 订单ID，成交所属订单的ID |
| trade-id | integer | 否 | Unique trade ID (NEW)唯一成交编号，成交时产生的唯一编号ID |
| price | string | 是 | 成交价格 |
| source | string | 是 | 订单来源<br>api |
| symbol | string | 是 | 交易对<br>btcusdt, ethbtc, rcneth ... |
| type | string | 是 | 订单类型<br>buy-market, sell-market, buy-limit, sell-limit, buy-ioc, sell-ioc, buy-stop-limit, sell-stop-limit, buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| role | string | 是 | 成交角色<br>maker,taker |
| filled-points | string | 是 | 抵扣数量（可为htx或hbpoint） |
| fee-deduct-currency | string | 是 | 抵扣类型<br>如果为空，代表扣除的手续费是原币；如果为"ht"，代表抵扣手续费的是HT；如果为"hbpoint"，代表抵扣手续费的是点卡 |
| fee-deduct-state | string | 是 | 抵扣状态<br>抵扣中：ongoing，抵扣完成：done |
|  time-in-force | string | 否 | 交易时效性<br>rpi : rpi订单 <br>gtc: 普通订单<br>ioc: ioc订单<br>fok: fok订单 |
| </data> |  | 否 |  |

**响应参数说明**：<br/>-filled-fees中的交易返佣金额可能不会实时到账。

## 请求示例
```http
curl"https://api.huobi.pro/v1/order/orders/{order-id}/matchresults
```
