# /v1/order/orders/batchCancelOpenOrders (批量撤销所有订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4480b-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 50次/2s |
| 接口描述 | 此接口发送批量撤销所有（单次最大100个）订单的请求。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| account-id | string | 否 | 账户ID，取值参考 GET /v1/account/accounts |
| symbol | string | 否 | 交易代码列表（最多10 个symbols，多个交易代码间以逗号分隔），btcusdt, ethbtc...（取值参考/v1/common/symbols） |
| types | string | 否 | 订单类型组合，使用逗号分割<br>buy-market, sell-market, buy-limit, sell-limit, buy-ioc, sell-ioc, buy-stop-limit, sell-stop-limit, buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| side | string | 否 | 主动交易方向<br>“buy”或“sell”，缺省将返回所有符合条件尚未成交订单 |
| size | int | 否 | 撤销订单的数量<br>[0-100] |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| success-count | int | 是 | 成功取消的订单数 |
| failed-count | int | 是 | 取消失败的订单数 |
| next-id | long | 是 | 下一个可以撤销的订单号，返回-1表示没有可以撤销的订单 |
| </data> |  | 否 |  |

## 请求示例
```http
{
"account-id":"178211",
"symbol":"btcusdt",
"types":"buy-limite",
"side":"buy",
"size":100
}
```

## 响应示例
```json
{
"status":"ok",
"data":{
"success-count":2,
"failed-count":0,
"next-id":5454600
}
}
```
