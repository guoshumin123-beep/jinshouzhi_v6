# v1/order/cancelAllOrders (现货全部撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-193afabf891

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 1次/2s |
| 接口描述 | 可通过该接口撤销现货的全部挂单。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 否 | 交易对,即btcusdt, ethbtc...（取值参考GET /v1/common/symbols），批量则可使用“,”分隔，为空则撤销所有交易对， |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |

## 请求示例
```http
{
  "symbol": "btcusdt"
}
```

## 响应示例
```json
{
  "status": "ok"
}
```
