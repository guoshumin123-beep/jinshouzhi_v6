# /v1/order/auto/place (杠杆下单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=10000065-77b7-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 100次/2s |
| 接口描述 | 杠杆自动借贷下单或还款,暂不支持子账户使用自动借款与自动还款。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 是 | 交易对 |
| account-id | string | 是 | 账户 ID，取值参考 GET /v1/account/accounts。现货交易使用 ‘spot’ 账户的 account-id；逐仓杠杆交易，请使用 ‘margin’ 账户的 account-id；全仓杠杆交易，请使用 ‘super-margin’ 账户的 account-id |
| amount | string | 是 | 订单交易量（市价买单为订单交易额）；市价单时，amount和market-amount只能二选一，0表示不传； |
| market-amount | string | 否 | 市价单买单为订单交易量，卖单为订单交易金额；amount和market-amount只能二选一，0表示不传； |
| borrow-amount | string | 否 | 需要发起借贷的数量，自动借款时必传。保留小数点后三位，且向上进一位，举例说明:12.98766，实际您输入12.988即可。该逻辑与web/app同步。 |
| type | string | 是 | 订单类型 <br>订单类型，包括buy-market, sell-market, buy-limit, sell-limit, buy-ioc, sell-ioc,buy-limit-maker, sell-limit-maker, buy-stop-limit, sell-stop-limit, buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| trade-purpose | string | 是 | 交易目的 {1:自动借贷, 2:自动还款} |
| price | string | 否 | 订单价格 |
| stop-price | string | 否 | 止盈止损, 触发价格 |
| operator | string | 否 | 止盈止损, 触发条件, gte或者lte |
| source | string | 是 | 订单来源 .现货交易填写“spot-api”，逐仓杠杆交易填写“margin-api”，全仓杠杆交易填写“super-margin-api”, C2C杠杆交易填写"c2c-margin-api" |
|  time-in-force | string | 否 | rpi订单 （ type 必须为 buy-limit，sell-limit）<br>rpi |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | Integer | 是 | 响应码 |
| success | Boolean | 是 | 是否成功 |
| message | String | 否 | 响应消息 |
| data | OrderResp | 否 | 响应订单参数 |
| orderId | long | 是 | 订单id |

## 请求示例
```http
{
             "market-amount":"10",
             "account-id":31253990,
             "source":"super-margin-web",
             "type":"buy-market",
             "symbol":"btcusdt",
             "trade-purpose":"2"
         }
```

## 响应示例
```json
{
             "code":200,
             "data":{
                 "order-id":912928425935415
             },
             "message":null,
             "success":true
         }
```
