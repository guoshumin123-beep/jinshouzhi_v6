# /v1/order/orders/{order-id}/submitcancel (撤销订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec44544-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 100次/2s |
| 接口描述 | 此接口发送一个撤销订单的请求。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| order-id | string | 是 | 订单ID，填在path中 |
| symbol | string | 否 | 交易对，填在URL请求参数中 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |
| data | long | 否 | 撤单单号 |

**响应参数说明**：<br/>返回的主数据对象1一个对应下单单号的字符串。<br/>

## 请求示例
```http
{
"order-id":"178211",
"symbol":"btcusdt"
}
```

## 响应示例
```json
{
"status":"ok",
"data":"356501495694025"
}
```
