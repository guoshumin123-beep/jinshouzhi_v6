# /v1/order/history (搜索最近48小时内历史订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43c9f-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 此接口基于搜索条件查询最近48小时内历史订单。通过API创建的订单，撤销超过2小时后无法查询。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbol | string | 否 | 交易对<br>btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| start-time | long | 否 | 查询起始时间（含）<br>UTC time in millisecond |
| end-time | long | 否 | 查询结束时间（含）<br>UTC time in millisecond |
| direct | string | 否 | 订单查询方向（注：仅在检索出的总条目数量超出size字段限定时起作用；如果检索出的总条目数量在size 字段限定内，direct 字段不起作用。）<br>prev 向前, next 向后 |
| size | int | 否 | 每次返回条目数量<br>[10-1000],最低参数值为10 |
| sort-by | String | 否 | 排序方式，created-at：按订单创建时间排序<br>updated-at：按订单最后更新时间排序<br>created-at，updated-at |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态 |
| <data> | object | 是 |  |
| account-id | long | 是 | 账户 ID |
| amount | string | 是 | 订单数量 |
| canceled-at | long | 否 | 接到撤单申请的时间 |
| created-at | long | 是 | 订单创建时间 |
| field-amount | string | 是 | 已成交数量 |
| field-cash-amount | string | 是 | 已成交总金额 |
| field-fees | string | 是 | 已成交手续费（准确数值请参考matchresults接口） |
| finished-at | long | 否 | 最后成交时间 |
| id | long | 是 | 订单ID，无大小顺序 |
| client-order-id | string | 否 | 用户自编订单号 |
| price | string | 是 | 订单价格 |
| source | string | 是 | 订单来源<br>所有可能的订单来源（见本章节简介） |
| canceled-source | string | 是 | 撤单来源<br>"timeout-canceled-order":"api超时撤单"、"cross-margin-fl-sys":"爆杠杠全仓爆仓"、"isolated-margin-fl-sys":"杠杠逐仓爆仓"、"coin-listing-delisting":"上币下币"、"api":"用户API订单"、"user-actively-cancels-order-web":"用户主动撤单-web"、"user-actively-cancels-order-ios":"用户主动撤单-ios"、"user-actively-cancels-order-android":"用户主动撤单-android"、"admin":"MGT后台操作"、"grid-end":"网格终止触发"、"system-manually-cancels-order":"系统手动撤销订单"、"circuit":"市价单熔断"、"self_match_prevent":"防自成交撤单"、"market":"市价单撤单"、"fok":"FOK撤单"、"ioc":"IOC撤单"、 "limit_maker":"limit-maker撤单"、"rpi_cancel"："RPI订单价格不可与非RPI订单交叉" |
| state | string | 是 | 订单状态<br>partial-canceled 部分成交撤销, filled 完全成交, canceled 已撤销 |
| symbol | string | 是 | 交易对<br>btcusdt, ethbtc, rcneth ... |
| stop-price | string | 否 | 止盈止损订单触发价格 |
| operator | string | 否 | 止盈止损订单触发价运算符<br>gte,lte |
| type | string | 是 | 订单类型<br>buy-market, sell-market, buy-limit, sell-limit, buy-ioc, sell-ioc, buy-stop-limit, sell-stop-limit, buy-limit-fok, sell-limit-fok, buy-stop-limit-fok, sell-stop-limit-fok |
| role | string | 是 | 订单成交方向 假设该订单是taker成交，则role返回taker的枚举 假设该订单是mkaer成交，则role返回maker的枚举 假设该订单是既有taker成交也有maker成就，则role返回both的枚举 默认是none<br>taker或maker或both |
| is-ice | boolean | 否 | 是否是冰山单，true：是，false：否 |
| ice-amount | string | 否 | 冰山单单次下单数量 |
|  time-in-force | string | 否 | 交易时效性<br>交易时效性 |
| updated-at | long | 是 | 订单更新时间（撤销时间，成交时间等） |
| </data> |  | 否 |  |
| next-time | long | 否 | 下一查询起始时间（当请求字段”direct”为”prev”时有效）, 下一查询结束时间（当请求字段”direct”为”next”时有效）。注：仅在检索出的总条目数量超出size字段限定时，此返回字段存在。<br>UTC time in millisecond |

**响应参数说明**：<br/>返回的主数据对象为一个对象数组，其中每一个元件代表一个交易结果。
