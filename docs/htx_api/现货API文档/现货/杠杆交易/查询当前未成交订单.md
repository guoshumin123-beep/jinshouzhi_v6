# /v1/order/openOrders (查询当前未成交订单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec43f47-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 50次/2s |
| 接口描述 | 查询已提交但1仍未完全成交或未被撤销的订单。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| account-id | string | 否 | 账户 ID，取值参考 GET /v1/account/accounts。现货交易使用‘spot’账户的 account-id；逐仓杠杆交易，请使用 ‘margin’ 账户的 account-id；全仓杠杆交易，请使用 ‘super-margin’ 账户的 account-id；c2c杠杆交易，请使用borrow账户的account-id |
| symbol | string | 否 | 交易对,即btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| side | string | 否 | 指定只返回某一个方向的订单，可能的值有: buy, sell. 默认两个方向都返回。 |
| types | string | 否 | 查询的订单类型组合，使用逗号分割 |
| from | string | 否 | 查询起始 ID，如果是向后查询，则赋值为上一次查询结果中得到的最后一条id ；如果是向前查询，则赋值为上一次查询结果中得到的第一条id |
| direct | string | 否 | 查询方向，prev 向前；next 向后。如字段'from'已设定，此字段'direct'为必填 |
| size | int | 否 | 返回订单的数量，最大值500。 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态 |
| <data> | object | 否 |  |
| id | long | 否 | 订单id，无大小顺序，可作为下一次翻页查询请求的from字段 |
| client-order-id | string | 否 | 用户自编订单号 |
| symbol | string | 否 | 交易对, 例如btcusdt, ethbtc |
| price | string | 否 | limit order的交易价格 |
| created-at | long | 否 | 订单创建的调整为新加坡时间的时间戳，单位毫秒 |
| type | string | 否 | 订单类型 |
| filled-amount | string | 否 | 订单中已成交部分的数量 |
| filled-cash-amount | string | 否 | 订单中已成交部分的总价格 |
| filled-fees | string | 否 | 已交交易手续费总额（准确数值请参考matchresults接口） |
| source | string | 否 | 订单来源 |
| state | string | 否 | 订单状态，包括created, submitted, partial-filled |
| stop-price | string | 否 | 止盈止损订单触发价格 |
| operator | string | 否 | 止盈止损订单触发价运算符 |
| is-ice | boolean | 是 | 是否是冰山单，true：是，false：否 |
| ice-amount | string | 否 | 冰山单单次下单数量 |
|  time-in-force | string | 否 | rpi订单<br>rpi |
| </data> |  | 否 |  |

```http
curl"https://api.huobi.pro/v1/order/openOrders?account-id=100009&symbol=ethusdt&side=buy"
```
