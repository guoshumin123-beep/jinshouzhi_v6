# 子用户

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=406

子用户可以用来隔离资产与交易，资产可以在母子用户之间划转；子用户只能在子用户内进行交易，并且子用户之间资产不能直接划转，只有母用户有划转权限。

子用户拥有独立的登录账号密码和 API Key，均由母用户在网页端进行管理。

每个母用户可创建200个子用户，每个子用户可创建20组Api Key，每个Api Key可对应设置读取、交易两种权限。

子用户的 API Key 也可绑定 IP 地址, 有效期的限制与母用户的API Key一致。

您可以点击 [这里 ](https://account.hbg.com/zh-cn/subaccount/management/) 创建子用户并管理。

子用户可以访问所有公共接口，包括基本信息和市场行情，子用户可以访问的私有接口如下：

|---|---|---|
| POST /v1/order/orders/place | 创建并执行订单 |  |
| POST /v1/order/orders/{order-id}/submitcancel | 撤销一个订单 |  |
| POST /v1/order/orders/submitCancelClientOrder | 撤销订单（基于client order ID） |  |
| POST /v1/order/orders/batchcancel | 批量撤销订单 |  |
| POST /v1/order/orders/batchCancelOpenOrders | 撤销当前委托订单 |  |
| GET /v1/order/orders/{order-id} | 查询一个订单详情 |  |
| GET /v1/order/orders | 查询当前委托、历史委托 |  |
| GET /v1/order/openOrders | 查询当前委托订单 |  |
| GET /v1/order/matchresults | 查询成交 |  |
| GET /v1/order/orders/{order-id}/matchresults | 查询某个订单的成交明细 |  |
| GET /v1/account/accounts | 查询当前用户的所有账户 |  |
| GET /v1/account/accounts/{account-id}/balance | 查询指定账户的余额 |  |
| POST /v1/futures/transfer | 币币与合约账户间的资产划转 |  |
| POST /v1/dw/transfer-in/margin | 从币币交易账户划转至杠杆账户 |  |
| POST /v1/dw/transfer-out/margin | 从杠杆账户划转至币币交易账户 |  |
| POST /v1/margin/orders | 申请借币 |  |
| POST /v1/margin/orders/{order-id}/repay | 归还借币 |  |
| GET /v1/margin/loan-orders | 查询借币记录 |  |
| GET /v1/margin/accounts/balance | 查询杠杆账户余额 |  |
| GET /v1/account/history | 查询账户流水 |  |
| POST /v1/cross-margin/transfer-in | 资产划转 |  |
| POST /v1/cross-margin/transfer-out | 资产划转 |  |
| GET /v1/cross-margin/loan-info | 查询借币币息率及额度 |  |
| POST /v1/cross-margin/orders | 申请借币 |  |
| POST /v1/cross-margin/orders/{order-id}/repay | 归还借币 |  |
| GET /v1/cross-margin/loan-orders | 查询借币订单 |  |
| GET /v1/cross-margin/accounts/balance | 借币账户详情 |  |
| GET /v2/account/ledger | 查询财务流水 |  |
| POST /v1/account/transfer | 资产划转 |  |
| GET /v2/point/account | 查询点卡余额 |  |
| POST /v2/point/transfer | 点卡划转 |  |
| GET /v2/etp/reference | 杠杆ETP基础参考信息 |  |
| POST /v2/etp/creation | 杠杆ETP换入 |  |
| POST /v2/etp/redemption | 杠杆ETP换出 |  |
| GET /v2/etp/transactions | 获取杠杆ETP换入换出记录 |  |
| GET /v2/etp/transaction | 获取特定杠杆ETP换入换出记录 |  |
| GET /v2/etp/rebalance | 获取杠杆ETP调仓记录 |  |
其他接口子用户不可访问，如果尝试访问，系统会返回 “error-code 403”。
