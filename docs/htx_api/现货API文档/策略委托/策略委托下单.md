# /v2/algo-orders (策略委托下单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4698b-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 20次/2s |
| 接口描述 | 仅可通过此节点下单策略委托，不可通过现货/杠杆交易相关接口下单策略委托，支持未触发OPEN订单最大数量为100。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| accountId | integer | 是 | 账户编号<br>当前仅支持spot账户ID、margin账户ID、super-margin账户ID，暂不支持c2c-margin账户ID |
| symbol | string | 是 | 交易代码 |
| orderPrice | string | 否 | 订单价格（对市价单无效） |
| orderSide | string | 是 | 订单方向<br>buy,sell |
| orderSize | string | 否 | 订单数量（对市价买单无效） |
| orderValue | string | 否 | 订单金额（仅对市价买单有效） |
| timeInForce | string | 否 | 订单有效期<br>gtc(对orderType=market无效),boc(对orderType=market无效),ioc,fok(对orderType=market无效) |
| orderType | string | 是 | 订单类型<br>limit,market |
| clientOrderId | string | 是 | 用户自编订单号（最长64位） |
| stopPrice | string | 是 | 触发价 |
| trailingRate | string | 否 | 回调幅度（仅对追踪委托有效）<br>[0.001-0.050] |

**请求参数说明**：<br/>•orderPrice与stopPrice的偏离率不能超出交易所对该币对的价格限制（百分比），例如，当交易所限定，限价买单的订单价格不能高于市价的110%时，该限制比率也同样适用于orderPrice与stopPrice之比。<br/>•用户须保证策略委托在触发时，其clientOrderId不与该用户的其它（8小时内）订单重复，0则，会导致触发失败。<br/>•用户须保证相关账户（accountId）中存有足够资金作为委托保证金，0则将导致策略委托触发时校验失败。<br/>•timeInForce字段中各枚举值含义：gtc-goodtillcancel(除非用户主动撤销0则一直有效)，boc-bookorcancel（即postonly，或称bookonly，除非成功挂单0则自动撤销），ioc-immediateorcancel（立即成交剩余部分自动撤销），fok-fillorkill（立即全部成交0则全部自动撤销）<br/>

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| clientOrderId | string | 是 | 用户自编订单号 |
| </data> |  | 否 |  |
