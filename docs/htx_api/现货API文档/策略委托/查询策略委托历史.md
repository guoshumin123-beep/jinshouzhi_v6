# /v2/algo-orders/history (查询策略委托历史)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46cbb-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 以orderOrigTime检索<br>历史终态订单包括，触发前被主动撤销的策略委托（orderStatus=canceled），触发失败的策略委托（orderStatus=rejected），触发成功的策略委托（orderStatus=triggered）。<br>如需查询已成功触发订单的后续状态，须通过现货/杠杆交易相关接口完成<br>触发前被主动撤销的策略委托及触发失败的策略委托，可通过此节点查询，但不可通过现货/杠杆交易相关接口查询 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| accountId | integer | 否 | 账户编号 |
| symbol | string | 是 | 交易代码 |
| orderSide | string | 否 | 订单方向<br>buy,sell |
| orderType | string | 否 | 订单类型<br>limit,market |
| orderStatus | string | 是 | 订单状态<br>canceled,rejected,triggered |
| startTime | long | 否 | 远点时间 |
| endTime | long | 否 | 近点时间 |
| sort | string | 否 | 检索方向<br>asc - 由远及近, desc - 由近及远 |
| limit | integer | 否 | 单页最大返回条目数量<br>[1-500] |
| fromId | long | 否 | 起始编号（仅在下页查询时有效） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 | 按用户请求参数sort指定顺序排列 |
| accountId | integer | 是 | 账户编号 |
| source | string | 是 | 订单来源 |
| clientOrderId | string | 是 | 用户自编订单号 |
| orderId | string | 否 | 订单编号（仅对orderStatus=triggered有效） |
| symbol | string | 是 | 交易代码 |
| orderPrice | string | 是 | 订单价格（对市价单无效） |
| orderSize | string | 否 | 订单数量（对市价买单无效） |
| orderValue | string | 否 | 订单金额（仅对市价买单有效） |
| orderSide | string | 是 | 订单方向 |
| timeInForce | string | 是 | 订单有效期 |
| orderType | string | 是 | 订单类型 |
| stopPrice | string | 是 | 触发价 |
| trailingRate | string | 否 | 回调幅度（仅对追踪委托有效） |
| orderOrigTime | long | 是 | 订单创建时间 |
| lastActTime | long | 是 | 订单最近更新时间 |
| orderCreateTime | long | 否 | 订单触发时间（仅对orderStatus=triggered有效） |
| orderStatus | string | 是 | 订单状态（triggered,canceled,rejected） |
| errCode | integer | 否 | 订单被拒状态码（仅对orderStatus=rejected有效） |
| errMessage | string | 否 | 订单被拒错误消息（仅对orderStatus=rejected有效） |
| </data> |  | 否 |  |
| nextId | long | 否 | 下页起始编号（仅在查询结果需要分页返回时传此字段） |

```http
curl"https://api.huobi.pro/v2/algo-orders/history?accountId=xxxx&symbol=xxxx&orderSide=xxx&orderType=limite&orderStatus=canceled"
```
