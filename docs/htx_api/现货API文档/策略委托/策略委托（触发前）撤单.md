# /v2/algo-orders/cancellation (策略委托（触发前）撤单)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46b88-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 20次/2s |
| 接口描述 | 单次请求最多批量撤销50张订单<br>如需撤销已成功触发的订单，须通过现货/杠杆交易相关接口完成<br>如需撤销未触发的订单，仅可通过此节点撤销，不可通过现货/杠杆交易相关接口撤销 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| clientOrderIds | string | 是 | 用户自编订单号（可多填，以数组的形式传输） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 | 按用户请求顺序排列 |
| accepted | string[] | 是 | 已接受订单clientOrderId列表 |
| rejected | string[] | 是 | 已拒绝订单clientOrderId列表 |
| </data> |  | 否 |  |

## 请求示例
```http
{
"clientOrderIds":[
"zy0002","zy0003"
]
}
```

## 响应示例
```json
{
"code":200,
"data":{
"accepted":[
"zy0002",
"zy0003"
],
"rejected":[]
}
}
```
