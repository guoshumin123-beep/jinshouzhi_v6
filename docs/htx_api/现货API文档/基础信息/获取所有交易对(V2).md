# /v2/settings/common/symbols (获取所有交易对(V2))

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec47f16-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ts | long | 否 | 增量时间戳 |

**请求参数说明**：<br/>传ts后查询出来的数据，1这个时间到当前时间这个接口更新的数据。如果没有更新查询出来的data为"[]"。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 返回状态 |
| <data> | Object | 否 |  |
| si | string | 否 | 交易对逐仓杠杆状态，online：上线，offline：下线 |
| scr | string | 否 | 交易对全仓杠杆状态，online：上线，offline：下线 |
| sc | string | 否 | 交易对（外） |
| dn | string | 否 | 交易对显示名称 |
| bc | string | 否 | 基础币种 |
| bcdn | string | 否 | 基础币种显示名称 |
| qc | string | 否 | 计价币种 |
| qcdn | string | 否 | 计价币种显示名称 |
| state | string | 否 | 交易对状态。 unknown：未知，not-online：未上线，pre-online：预上线，online：已上线，suspend：暂停，offline：已下线，transfer-board：转版，fuse：熔断（风控系统控制） |
| whe | boolean | 否 | 是否白名单 |
| cd | boolean | 否 | 是否在国家黑名单 |
| te | boolean | 否 | 是否可交易 |
| toa | long | 否 | 交易开始时间 |
| sp | string | 否 | 交易对分区 |
| w | int | 否 | 排序权重 |
| ttp | decimal(10,6) | 否 | 交易总精度 |
| tap | decimal(10,6) | 否 | 交易数量精度 |
| tpp | decimal(10,6) | 否 | 交易价格精度 |
| fp | decimal(10,6) | 否 | 费用精度 |
| suspend_desc | string | 否 | 暂停文案 |
| transfer_board_desc | string | 否 | 转板文案 |
| tags | string | 否 | 标签，多个标签以逗号分隔，如：st,hadax |
| lr | decimal | 否 | 杠杆率，如：3.5，如果交易对不支持杠杆，则为null |
| smlr | decimal | 否 | 全仓杠杆率，如：3，如果交易对不支持全仓杠杆，则为null。2020年9月15日以后上线的交易对，这个字段不返回取值，您可通过/v1/settings/common/market-symbols进行查询。 |
| flr | String | 否 | C2C杠杆率，如："3"，如果交易对不支持C2C，则为null |
| wr | string | 否 | 提币风险率，如：3，如果交易对不支持全仓杠杆，则为null |
| d | int | 否 | 多空方向：1多2空 |
| elr | string | 否 | ETP交易对杠杆倍数 |
| p | Object | 否 |  |
| castate | string | 否 | 非必须. 集合竞价的状态；当处于集合竞价的第1和第2阶段的时候，才会展示。枚举值："ca_1", "ca_2" |
| ca1oa | long | 否 | 非必须. 配置了配置集合竞价的交易对才有该信息，自UTC 1970年1月1日0时0分0秒0毫秒到现在的总毫秒数 |
| ca2oa | long | 否 | 非必须. 配置了配置集合竞价的交易对才有该信息，自UTC 1970年1月1日0时0分0秒0毫秒到现在的总毫秒数 |
| enable_rpi | boolean | 否 | 是否支持RPI订单 |
| </data> |  | 否 |  |
| ts | String | 否 | 增量接口数据时间戳 |
| full | int | 否 | 增量接口数据类型标识： 0 增量， 1全量 |
| err_code | string | 否 | 错误码 (接口报错时返回) |
| err_msg | string | 否 | 错误信息 (接口报错时返回) |
