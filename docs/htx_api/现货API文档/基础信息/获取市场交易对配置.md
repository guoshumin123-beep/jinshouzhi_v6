# /v1/settings/common/market-symbols (获取市场交易对配置)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec456a5-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| symbols | string | 否 | 查询的交易对组合，不填表示所有交易对，多个交易对请使用 , 分隔 |
| ts | long | 否 | 增量时间戳 |

**请求参数说明**：<br/>传ts后查询出来的数据，1这个时间到当前时间这个接口更新的数据。如果没有更新查询出来的data为"[]"。
