# /v2/market-status (获取当前市场状态)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec474aa-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | - |
| 接口描述 | 此节点返回当前最新市场状态。<br>状态枚举值包括:1-正常（可下单可撤单），2-挂起（不可下单不可撤单），3-仅撤单（不可下单可撤单）。<br>挂起原因枚举值包括:2-紧急维护，3-计划维护。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

**请求参数说明**：<br/>此接口不接受任何参数。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 交易对,即btcusdt, ethbtc...（取值参考GET /v1/common/symbols） |
| message | string | 否 | 状态码 |
| <data> | object | 是 | 错误描述（如有） |
| marketStatus | integer | 是 |  |
| haltStartTime | long | 否 | 市场状态（1=normal, 2=halted, 3=cancel-only） |
| haltEndTime | long | 否 | 市场暂停开始时间（unix time in millisecond），仅对marketStatus=halted或cancel-only有效 |
| haltReason | integer | 否 | 市场暂停预计结束时间（unix time in millisecond），仅对marketStatus=halted或cancel-only有效；如在marketStatus=halted或cancel-only时未返回此字段，意味着市场暂停结束时间暂时无法预计 |
| affectedSymbols | string | 否 | 市场暂停原因（2=emergency-maintenance, 3=scheduled-maintenance），仅对marketStatus=halted或cancel-only有效 |
| </data> |  | 否 | 市场暂停影响的交易对列表，以逗号分隔，如影响所有交易对返回"all"，仅对marketStatus=halted或cancel-only有效 |

## 请求示例
```http
curl"https://api.huobi.pro/v2/market-status"
```

## 响应示例
```json
{
"code":200,
"message":"success",
"data":{
"marketStatus":1
}
}
```
