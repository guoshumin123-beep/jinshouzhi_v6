# /v1/common/timestamp (获取当前系统时间戳)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec414b4-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | - |
| 接口描述 | 此接口返回当前的系统时间戳，即从 UTC 1970年1月1日0时0分0秒0毫秒到现在的总毫秒数。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

**请求参数说明**：<br/>此接口不接受任何参数。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 请求处理结果 |
| data | long | 是 | 当前系统时间戳 |

## 请求示例
```http
curl"https://api.huobi.pro/v1/common/timestamp"
```

## 响应示例
```json
{
"status":"ok",
"data":1629715504949
}
```
