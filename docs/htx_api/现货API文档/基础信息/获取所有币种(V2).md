# /v2/settings/common/currencies (获取所有币种(V2))

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec47ceb-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ts | long | 否 | 增量时间戳 |

**请求参数说明**：<br/>传ts后查询出来的数据，1这个时间到当前时间这个接口更新的数据。如果没有更新查询出来的data为"[]"。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 返回状态 |
| <data> | Object | 否 |  |
| cc | string | 否 | 币种 |
| dn | string | 否 | 币种显示名称 |
| fn | string | 否 | 币种全称 |
| at | int | 否 | 资产类型，1 虚拟币 2 法币 |
| wp | int | 否 | 提币精度 |
| ft | string | 否 | 手续费类型，eth:固定手续费，btc:区间手续费 husd:按照比例收取手续费 |
| dma | string | 否 | 最小充币额度 |
| wma | string | 否 | 最小提币额度 |
| sp | string | 否 | 显示精度 |
| w | string | 否 | 权重 |
| qc | boolean | 否 | 是否是计价货币 |
| state | string | 否 | 币种状态。 unkown：未知，not-online：未上线 ，online：已上线 ，offline：已下线 |
| v | boolean | 否 | 是否可见--下线币种但有资产的用户可见 |
| whe | boolean | 否 | 用户是否属于币种白名单 |
| cd | boolean | 否 | 用户所属国家是否在币种黑名单中--在黑名单但有资产是否可见 |
| de | boolean | 否 | 充值是否开启 |
| wed | boolean | 否 | 提币是否开启 |
| cawt | boolean | 否 | 币种地址是否带tag |
| fc | int | 否 | 快速上账区块确认次数 |
| sc | int | 否 | 安全上账区块确认次数 |
| swd | string | 否 | 挂起时提币文案 |
| wd | string | 否 | 提币文案 |
| sdd | string | 否 | 挂起时充币文案 |
| dd | string | 否 | 充币文案 |
| svd | string | 否 | 挂起时资产文案 |
| tags | string | 否 | 标签，多个标签以逗号分隔，如：st,hadax |
| </data> |  | 否 |  |
| ts | String | 否 | 增量接口数据时间戳 |
| full | int | 否 | 增量接口数据类型标识： 0 增量， 1全量 |
| err_code | string | 否 | 错误码 (接口报错时返回) |
| err_msg | string | 否 | 错误信息 (接口报错时返回) |

## 请求示例
```http
curl"https://api.huobi.pro/v2/settings/common/currencies"
```
