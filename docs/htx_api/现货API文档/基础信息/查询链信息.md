# /v1/settings/common/chains (查询链信息)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec45226-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| show-desc | string | 否 | 全量列表时文案参数, 0:无文案 1:全部文案 2:暂停充提和换链文案 |
| currency | string | 否 | 币种 |
| ts | long | 否 | 增量时间戳 |

**请求参数说明**：<br/>传ts后查询出来的数据，1这个时间到当前时间这个接口更新的数据。如果没有更新查询出来的data为"[]"。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 返回状态 |
| <data> | Object | 否 |  |
| adt | boolean | 否 | 充值地址是否有tag |
| ac | string | 否 | 地址复用哪个链，比如ERC20各链都使用eth地址 |
| ao | boolean | 否 | 是否一次性地址 |
| awt | boolean | 否 | 链上地址是否支持tag |
| chain | string | 否 | 链名 |
| ct | string | 否 | 链类型 plain普通 live多链有效 old换链中老链 new换链中新链 legal法币通道 tooold换链已结束老链 |
| code | string | 否 | 已废弃，等同于链名chain |
| currency | string | 否 | 所属币种 |
| deposit-desc | string | 否 | 充值描述文案 |
| de | boolean | 否 | 是否可充值 |
| dma | string | 否 | 充值上账最小金额，小于此金额会：1.小额累计超过deposit-min-amount再上账 2. 小额不累计，永不上账 |
| deposit-tips-desc | string | 否 | 充值描述信息tips |
| dn | string | 否 | 链显示名，一般大写 |
| fc | integer | 否 | 充值快速上账次数，当前交易所在链节点的高度距离链尾距离长度大于此数时，充提通知清算给用户上账，此充值订单视为不安全充值，在提币和账户划转时可用金额需排除此订单等价金额 |
| ft | string | 否 | 手续费类型 |
| default | integer | 否 | 是否默认链 |
| replace-chain-info-desc | string | 否 | 换链描述信息 |
| replace-chain-notification-desc | string | 否 | 换链提示信息 |
| replace-chain-popup-desc | string | 否 | 换链弹窗信息 |
| ca | string | 否 | 合约地址 |
| cct | integer | 否 | 链合约类型 0; coin; 1: token |
| sc | integer | 否 | 充值安全上账次数，当前交易所在链节点的高度距离链尾距离长度大于此数时，资管DW标记此订单为安全充值，在提币和账户划转时视为可用金额 |
| sda | string | 否 | 暂停充值公告信息 |
| suspend-deposit-desc | string | 否 | 暂停充值描述信息 |
| swa | string | 否 | 暂停提币公告信息 |
| suspend-withdraw-desc | string | 否 | 暂停提币描述信息 |
| v | boolean | 否 | 是否可见 |
| withdraw-desc | string | 否 | 提币描述文案 |
| we | boolean | 否 | 是否可提币 |
| wma | string | 否 | 提币最小金额，小于此金额拒绝提币 |
| wp | integer | 否 | 提币数值精度，金额大于此精度拒绝提币 |
| fn | string | 否 |  |
| withdraw-tips-desc | string | 否 | 提币弹窗提示 |
| suspend-visible-desc | string | 否 | 暂停可见文案 |
| </data> |  | 否 |  |
| ts | String | 否 | 增量接口数据时间戳 |
| full | int | 否 | 增量接口数据类型标识： 0 增量， 1全量 |
| err-code | string | 否 | 错误码 (接口报错时返回) |
| err-msg | string | 否 | 错误信息 (接口报错时返回) |

## 请求示例
```http
curl"https://api.huobi.pro/v1/settings/common/chains"
```
