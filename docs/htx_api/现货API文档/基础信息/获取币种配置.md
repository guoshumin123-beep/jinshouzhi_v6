# /v1/settings/common/currencys (获取币种配置)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec45521-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 接口描述 | - |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| ts | long | 否 | 增量时间戳 |

**请求参数说明**：<br/>传ts后查询出来的数据，1这个时间到当前时间这个接口更新的数据。如果没有更新查询出来的data为"[]"。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 返回状态 |
| <data> | Object | 否 |  |
| name | string | 否 | 币种名称 |
| dn | string | 否 | 币种显示名称 |
| vat | long | 否 | 资产可见开始时间 |
| det | long | 否 | 充币开启时间 |
| wet | long | 否 | 提币开放时间 |
| wp | int | 否 | 提币精度 |
| ct | string | 否 | 手续费类型，eth是固定手续费，btc是区间手续费 |
| cp | string | 否 | 支持的分区。 INVALID：无效分区，all：PRO and HADAX ， pro：PRO ， hadax：HADAX |
| ss | array | 否 | 支持的站点。unknown：未知类型，otc：OTC法币站，futures：币本位交割合约，minepool：矿池 （mulan不支持），institution：机构，swap：币本位永续合约，asset：资管（mulan不支持划转，仅用于对账），cfd：日本站cfd合约，chat：火信(IM)，option：合约期权，linear-swap：U本位合约，custody：香港站资金账户，turbine：涡轮，margin：逐仓杠杆，super-margin：全仓杠杆 |
| oe | integer | 否 | 0-没有开启， 1-开启 |
| dma | string | 否 | 最小充币额度 |
| wma | string | 否 | 最小提币额度 |
| sp | string | 否 | 显示精度 |
| w | string | 否 | 权重 |
| qc | boolean | 否 | 是否是计价货币 |
| state | string | 否 | 币种状态类型。 unkown：未知，not-online：未上线 ，online：已上线 ，offline：已下线 |
| v | boolean | 否 | 是否可见 |
| whe | boolean | 否 | 用户是否属于币种白名单 |
| cd | boolean | 否 | 用户所属国家是否在币种黑名单中 |
| de | boolean | 否 | 充值是否开启 |
| we | boolean | 否 | 提币是否开启 |
| cawt | boolean | 否 | 币种地址是否带tag |
| cao | boolean | 否 | 币种地址是否是一次性地址 |
| fc | int | 否 | 快速上账区块确认次数 |
| sc | int | 否 | 安全上账区块确认次数 |
| swd | string | 否 | 挂起时提币文案 |
| wd | string | 否 | 提币文案 |
| sdd | string | 否 | 挂起时充币文案 |
| dd | string | 否 | 充币文案 |
| svd | string | 否 | 挂起时资产文案 |
| tags | string | 否 | 标签，多个标签以逗号分隔，如：st,hadax |
| fn | string | 否 | 币种全称 |
| bc |  | 否 |  |
| iqc |  | 否 |  |
| </data> |  | 否 |  |
| ts | String | 否 | 增量接口数据时间戳 |
| full | int | 否 | 增量接口数据类型标识： 0 增量， 1全量 |
| err-code | string | 否 | 错误码 (接口报错时返回) |
| err-msg | string | 否 | 错误信息 (接口报错时返回) |

```http
curl"https://api.huobi.pro/v1/settings/common/currencys"
```
