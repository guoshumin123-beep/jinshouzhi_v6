# /v1/account/transfer (资产划转)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec41321-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 该节点为母用户和子用户进行资产划转的通用接口。<br><br>母用户和子用户均支持的功能包括：<br>1、币币账户与逐仓杠杠账户之间的划转；<br>2、逐仓杠杠不同账户间相同币种的直接划转，如逐仓杠杠BTC/USDT账户和ETH/USDT账户，相同币种USDT可直接划转；<br><br>仅母用户支持的功能包括：<br>1、母用户币币账户与子用户币币账户间的划转；<br>2、不同子用户币币账户间划转(FireBlocks子账户只能与FireBlocks子账户相互划转)；<br><br>仅子用户支持的功能包括：<br>1、子用户币币账户向母用户下的其他子用户币币账户划转(FireBlocks子账户只能与FireBlocks子账户相互划转,被托管的子账户禁止子子划转)，此权限默认关闭，需母用户授权。授权接口为POST/v2/sub-user/transferability；<br>2、子用户币币账户向母用户币币账户划转；<br><br>其他划转功能将逐步上线，敬请期待。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| from-user | long | 是 | 转出用户uid<br>母用户uid,子用户uid |
| from-account-type | string | 是 | 转出账户类型<br>spot,margin |
| from-account | long | 是 | 转出账户id |
| to-user | long | 是 | 转入用户uid<br>母用户uid,子用户uid |
| to-account-type | string | 是 | 转入账户类型<br>spot,margin |
| to-account | long | 是 | 转入账户id |
| currency | string | 是 | 币种，即btc, ltc, bch, eth, etc ...<br>取值参考GET /v1/common/currencys |
| amount | string | 是 | 划转金额 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 状态<br>"ok" or "error" |
| <data> | list | 是 |  |
| transact-id | int | 是 | 交易流水号 |
| transact-time | long | 是 | 交易时间 |
| </data> |  | 否 |  |

## 请求示例
```http
{
"from-user":178911,
"from-account-type":"spot",
"from-account":"178911",
"to-user":"178911",
"to-account-type":"spot",
"to-account":178911,
"currency":"usdt",
"amount":"1"
}
```

## 响应示例
```json
{
"status":"ok",
"data":{
"transact-id":220521190,
"transact-time":1590662591832
}
}
```
