# /v1/account/overview/info (可抵扣币种查询信息)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-18f7c43a996

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 5次/1s |
| 接口描述 | 用户查询可抵扣手续费的资产信息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 否 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| currency | string | 是 | 币种 |
| <data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/account/overview/info"
```

## 响应示例
```json
{
  "code": "200",
  "data": {
    "currency": "BTX"
  },
  "success": true
}
```
