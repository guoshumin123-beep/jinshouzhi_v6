# /v2/account/ledger (财务流水)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec4610b-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 接口描述 | 该节点基于用户账户ID返回财务流水。<br>一期上线暂时仅支持划转流水的查询（“transactType”=“transfer”）。<br>通过“startTime”/“endTime”框定的查询窗口最大为10天，意即，通过单次查询可检索的范围最大为10天。<br>该查询窗口可在最近180天范围内平移，意即，通过多次平移窗口查询，最多可检索到过往180天的记录。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| accountId | string | 是 | 账户编号 |
| currency | string | 否 | 币种 （缺省值所有币种） |
| transactTypes | string | 否 | 变动类型 <br>枚举值： transfer |
| startTime | long | 否 | 远点时间（180天） |
| endTime | long | 否 | 近点时间（180天） |
| sort | string | 否 | 检索方向（asc 由远及近, desc 由近及远）<br>(废弃) |
| limit | int | 否 | 单页最大返回条目数量 [1-500] |
| fromId | long | 否 | 起始编号（仅在下页查询时有效，见注3） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 | 按用户请求参数sort中定义的顺序排列 |
| accountId | integer | 是 | 账户编号 |
| currency | string | 是 | 币种 |
| transactAmt | number | 是 | 变动金额（入账为正 or 出账为负） |
| transactType | string | 是 | 变动类型<br>transfer（划转） |
| transferType | string | 否 | 划转类型（仅对transactType=transfer有效）<br>otc-to-spot（otc到现货）, spot-to-otc（现货到otc）, futures-to-spot（交割合约到现货）, spot-to-futures（现货到交割合约）, dm-swap-to-spot（币本位永续合约到现货）, dm-spot-to-swap（现货到币本位永续合约）,spot-to-linear-swap（现货到U本位合约）, linear-swap-to-spot（U本位合约到现货） margin-transfer-in（转入到逐仓杠杆）, margin-transfer-out（从逐仓杠杆转出）, spot-to-super-margin（现货到全仓杠杆）, super-margin-to-spot（全仓杠杆到现货）, master-transfer-in（转入到母用户）, master-transfer-out（从母用户转出）, sub-transfer-in（转入到子用户）, sub-transfer-out（从子用户转出） |
| transactId | integer | 是 | 交易流水号 |
| transactTime | integer | 是 | 交易时间 |
| transferer | integer | 否 | 付款方账户ID |
| transferee | integer | 否 | 收款方账户ID |
| </data> |  | 否 |  |
| nextId | integer | 否 | 下页起始编号（仅在查询结果需要分页返回时包含此字段，见注3。） |

**响应参数说明**：<br/>仅当用户请求查询的时间范围内的数据条目超出单页限制（由“limit“字段设定）时，服务器才返回”nextId“字段。用户收到服务器返回的”nextId“后–<br/>1）须知晓后续仍有数据未能在本页返回；<br/>2）如需继续查询下页数据，应再次请求查询并将服务器返回的“nextId”作为“fromId“，其它请求参数不变。<br/>3）作为数据库记录ID，“nextId”和“fromId”除了用来翻页查询外，无其它业务含义。

## 请求示例
```http
curl"https://api.huobi.pro/v2/account/ledger?accountId=xxxx&currency=BTC&transactTypes=transfer"
```
