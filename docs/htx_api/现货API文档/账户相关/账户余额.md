# /v1/account/accounts/{account-id}/balance (账户余额)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec40922-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 100次/2s |
| 接口描述 | 查询指定账户的余额，支持以下账户：<br><br>spot：现货账户，margin：逐仓杠杆账户，point：点卡账户，super-margin：全仓杠杆账户,，grid-trading：策略帐户，otc-options：期权帐户;<br>不支持OTC账户查询 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

**备注**：<br/>查询指定账户的余额，支持以下账户：<br/>spot：现货账户，margin：逐仓杠杆账户，point：点卡账户，super-margin：全仓杠杆账户，grid-trading：策略帐户，otc-options：期权帐户. 
不支持OTC账户查询

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| account-id | string | 是 | account-id填在 path 中<br>取值参考 GET /v1/account/accounts |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 请求处理结果<br>"ok","error" |
| <data> | object | 是 |  |
| id | long | 是 | 账户 ID |
| state | string | 是 | 账户状态<br>working：正常 lock：账户被锁定 |
| type | string | 是 | 账户类型<br>spot：现货账户, margin：逐仓杠杆账户, point：点卡账户, super-margin：全仓杠杆账户, 矿池账户: minepool, ETF账户: etf, 抵押借贷账户: crypto-loans，grid-trading：策略帐户，otc-options：期权帐户,trust-credit ：（ 三方信托记账账户 ) |
| <list> | Array | 否 |  |
| balance | string | 是 | 余额 |
| debt | string | 否 | 无效字段 |
| available | string | 否 | 无效字段 |
| currency | string | 是 | 币种 |
| type | string | 是 | 类型<br>trade: 交易余额,frozen: 冻结余额, loan: 待还借贷本金, interest: 待还借贷利息, lock: 锁仓, bank: 储蓄, credit-repay: 授信应还 (三方托管业务授信),trust-asset: 托管资金 |
| seq-num | string | 是 | 账户变更的序号 |
| </list> |  | 否 |  |
| </data> |  | 否 |  |

curl"https://api.huobi.pro/v1/account/accounts/{account-id}/balance"
