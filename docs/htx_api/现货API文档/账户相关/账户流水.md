# /v1/account/history (账户流水)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec41049-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 5次/2s |
| 接口描述 | 该节点基于用户账户ID返回账户流水。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| account-id | string | 是 | 账户编号,取值参考 GET /v1/account/accounts |
| currency | string | 否 | 币种,即btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys) |
| transact-types | string | 否 | 变动类型，可多选，以逗号分隔，包含动账类型列表详见注3<br>trade (交易),etf（ETF申购）, transact-fee（交易手续费）, fee-deduction（手续费抵扣）, transfer（划转）, credit（借币）, liquidation（清仓）, interest（币息）, deposit（充币），withdraw（提币）, withdraw-fee（提币手续费）, exchange（兑换）, other-types（其他）,rebate（交易返佣）, fireblocks-dw ( fireblocks 充提资产变动）, loan-disburse（场外借贷-放款）,loan-repay（场外借贷-还款）, loan-interest-refund（场外借贷-退还利息）,loan-interest-pay（场外借贷-还利） |
| start-time | long | 否 | 远点时间 unix time in millisecond. 以transact-time为key进行检索. 查询窗口最大为1小时. 窗口平移范围为最近30天.<br>[((end-time) – 1hour), (end-time)] |
| end-time | long | 否 | 近点时间unix time in millisecond. 以transact-time为key进行检索. 查询窗口最大为1小时. 窗口平移范围为最近30天.<br>[(current-time) – 29days,(current-time)] |
| sort | string | 否 | 检索方向<br>asc or desc |
| size | int | 否 | 最大条目数量<br>[1-500] |
| from-id | long | 否 | 起始编号（仅在下页查询时有效，见注2） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 状态码<br>"ok","error" |
| <data> | object | 否 |  |
| account-id | long | 否 | 账户编号 |
| currency | string | 否 | 币种 |
| transact-amt | string | 否 | 变动金额（入账为正 or 出账为负） |
| transact-type | string | 否 | 变动类型 |
| avail-balance | string | 否 | 可用余额 |
| acct-balance | string | 否 | 账户余额 |
| transact-time | long | 否 | 交易时间（数据库记录时间） |
| record-id | long | 否 | 数据库记录编号（全局唯一） |
| source-id | long | 否 | 来源业务ID。表示触发本次账户余额变动的上游业务操作的返回ID。 |
| </data> |  | 否 |  |
| next-id | long | 否 | 下页起始编号（仅在查询结果需要分页返回时包含此字段，见注2） |

**响应参数说明**：<br/>账户流水中返回的交易返佣为到账金额，多笔成交产生的多笔返佣可能会合并到帐，成为一笔流水。<br/>备注2：<br/>仅当用户请求查询的时间范围内的数据条目超出单页限制（由“size“字段设定）时,服务器才返回”next-id“字段。用户收到服务器返回的”next-id“后<br/>1）须知晓后续仍有数据未能在本页返回；<br/>2）如需继续查询下页数据，应再次请求查询并将服务器返回的“next-id”作为“from-id“，其它请求参数不变。<br/>3）作为数据库记录ID，“next-id”和“from-id”除了用来翻页查询外，无其它业务含义。<br/>备注3：<br/>变动类型包含动账类型明细列表：<br/>https://huobiapi.github.io/docs/spot/v1/cn/#84f1b5486d

## 请求示例
```http
curl"https://api.huobi.pro/v1/account/history?account-id=xxxxx&currency=BTC&transact-types=transfer&start-time=1667814703000&end-time=1667909627238&sort=asc&size=100&from-id=xxxxxxx"
```
