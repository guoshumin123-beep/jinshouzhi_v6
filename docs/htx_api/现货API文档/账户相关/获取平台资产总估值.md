# /v2/account/valuation (获取平台资产总估值)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46584-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 3次/1s |
| 接口描述 | 按照BTC或法币计价单位，获取平台账户的总资产估值。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| accountType | string | 否 | 账户类型，详见账户类型数据字典 |
| valuationCurrency | string | 否 | 不填默认为btc估值（目前暂只支持BTC估值，参数值需大写） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| <data> | object | 是 |  |
| totalBalance | string | 是 | 总账户资产，按估值参数计价 |
| todayProfit | string | 是 | 今日总收益，按估值参数计价 |
| todayProfitRate | string | 是 | 今日收益率 |
| <profitAccountBalanceList> | list | 是 |  |
| distributionType | string | 是 | 查询账户类型<br>1 币币账户<br>2 逐仓杠杆账户<br>3 全仓杠杆账户<br>4 交割合约账户<br>5 法币账户<br>6 矿池账户<br>7 永续合约账户<br>8 C2C出借账户<br>9 C2C借款账户<br>10 存币宝账户<br>11 正向合约账户<br>12 期权合约账户<br>13 场外期权账户<br>14 抵押借贷账户<br>15 网格交易账户<br>16 挖矿宝账户 |
| balance | float | 是 | 查询账户资产，按估值参数计价 |
| success | boolean | 是 | 查询账户资产是否成功 失败时accountBalance和balance为0 |
| accountBalance | string | 是 | 查询账户资产，按估值参数计价 |
| </profitAccountBalanceList> |  | 否 |  |
| <updated> | list | 是 |  |
| success | boolean | 是 | 今日收益是否已更新 |
| time | long | 是 | 收益更新日期 |
| </updated> |  | 否 |  |
| </data> |  | 否 |  |
| success | boolean | 是 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v2/account/valuation?accountTypency=spot&valuationCurrencyunt=BTC"
```
