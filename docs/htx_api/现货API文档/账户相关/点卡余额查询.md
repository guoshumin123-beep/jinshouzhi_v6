# /v2/point/account (点卡余额查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec47647-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/秒 |
| 接口描述 | 此节点既可查询到“不限时”点卡的余额，也可查询到“限时”点卡的余额、分组ID、及各组有效期。<br>此节点仅可查询到限时/不限时点卡的余额，不可查询到其它币种余额。<br>母用户可查询母用户或子用户点卡余额。<br>点卡兑换仅可通过官网页面或APP完成。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| subUid | string | 否 | 子用户UID（仅对母用户查询子用户点卡余额场景有效） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| success | string | 是 |  |
| <data> | object | 是 |  |
| accountId | string | 是 | 账户ID |
| accountStatus | string | 是 | 账户状态（working 正常, lock 锁定, fl-sys 系统自动爆仓, fl-mgt 手动爆仓, fl-end 爆仓结束, fl-negative 穿仓） |
| acctBalance | string | 是 | 账户余额 |
| <groupIds> | object | 是 | 点卡分组ID列表 |
| groupId | long | 是 | 点卡分组ID |
| expiryDate | long | 是 | 点卡到期日（unix time in millisecond） |
| remainAmt | string | 是 | 剩余数量 |
| </groupIds> |  | 否 |  |
| </data> |  | 否 |  |

**响应参数说明**：<br/>-限时点卡分组ID=母用户兑换该组限时点卡时的交易ID<br/>-不限时点卡分组ID=0<br/>-不限时点卡到期日=空

## 请求示例
```http
curl"https://api.huobi.pro/v2/point/account？subUid=xxxx"
```
