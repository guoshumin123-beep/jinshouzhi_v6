# /v1/account/accounts (账户信息)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec40743-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 100次/2s |
| 接口描述 | 查询当前用户的所有账户ID account-id 及其相关信息，<br>逐仓/全仓/C2C杠杆账户（margin/super-margin/borrow）会在第一次划转资产时创建，如果未划转过资产则不会有杠杆账户。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

**请求参数说明**：<br/>此接口不接受任何参数。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 请求处理结果<br>"ok","error" |
| <data> | object | 是 |  |
| id | long | 是 | account-id |
| state | string | 是 | 账户状态<br>working：正常, lock：账户被锁定 |
| type | string | 是 | 账户类型<br>spot：现货账户, margin：逐仓杠杆账户, point：点卡账户, super-margin：全仓杠杆账户，矿池账户: minepool, ETF账户: etf, 抵押借贷账户: crypto-loans，grid-trading：策略帐户，otc-options：期权帐户,trust-credit ：（ 三方信托记账账户 ) |
| subtype | string | 否 | 子账户类型（仅对逐仓杠杆账户以及 trust-credit 三方信托记账账户有效)<br>逐仓杠杆交易标的，例如btcusdt）;在trust-credit账户类型下，subtype上的值标识其资产或者授信资产所在链。可能取值包括（参考链信息）：btc, eth, usdterc20, trc20usdt, usdc, trx1等。 |
| </data> | object | 是 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/account/accounts"
```
