# /v2/point/transfer (点卡划转)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec477b1-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 限频 | 2次/秒 |
| 接口描述 | 此节点既可划转“不限时”点卡，也可划转“限时”点卡。<br>此节点仅支持不限时/限时点卡的划转，不支持其它币种的划转。<br>此节点仅支持母子用户点卡（point）账户间划转。<br>如果登录用户为母用户，该节点支持双向划转，即母向子划转和子向母划转。<br>如果登录用户为子用户，该节点仅支持单向划转，即子向母划转。<br>母用户将限时点卡从子用户转回时应先行查询子用户点卡的groupId。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| fromUid | string | 是 | 转出方UID |
| toUid | string | 是 | 转入方UID |
| groupId | long | 是 | 点卡分组ID |
| amount | string | 是 | 划转数量（最高精度: 8位小数） |

**请求参数说明**：<br/>如传参点卡分组ID=0，意味着该笔划转为不限时点卡划转。

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| success | string | 是 |  |
| <data> | object | 是 |  |
| transactId | string | 是 | 划转交易ID |
| transactTime | long | 是 | 划转交易时间（unix time in millisecond） |
| </data> |  | 否 |  |

## 请求示例
```http
{
"fromUid":"178911",
"toUid":"178211",
"groupId":178911,
"amount":"178911"
}
```

## 响应示例
```json
{
"code":200,
"data":{
"transactId":"74",
"transactTime":1594370136458
},
"success":true
}
```
