# /v1/futures/transfer (币币现货账户与合约账户划转)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec431cf-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 交易 |
| 接口描述 | 此接口用户币币现货账户与合约账户之间的资产划转。<br><br>从现货现货账户转至合约账户，类型为pro-to-futures;从合约账户转至现货账户，类型为futures-to-pro |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | string | 是 | 币种, e.g. btc |
| amount | decimal | 是 | 划转数量 |
| type | string | 是 | 划转类型<br>从合约账户到现货账户：“futures-to-pro”，从现货账户到合约账户： “pro-to-futures” |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | Long | 否 | Transfer id |
| status | string | 否 | "ok" or "error" |
| err-code | string | 否 | 错误码，具体错误码请见列表 |
| err-msg | string | 否 | 错误消息，具体消息内容请列表 |

## 请求示例
```http
{
"currency":"btc",
"amount":0.001,
"type":"pro-to-futures"
}
```

## 响应示例
```json
{
"data":12345,
"status":"ok"
}
```

## 失败示例
```json
{
"status":"error",
"data":null,
"err-code":"base-msg",
"err-msg":"Insufficientamountavailable."
}
```
