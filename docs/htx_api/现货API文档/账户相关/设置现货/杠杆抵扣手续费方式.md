# /v1/account/fee/switch (设置现货/杠杆抵扣手续费方式)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-18f7c45c497

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 2次/1s |
| 接口描述 | 用于设置现货/杠杆交易手续费用抵扣，可以使用点卡抵扣，也可以使用HTX抵扣。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| switchType | int | 是 | 0:点卡抵扣，1:币种抵扣，2:关闭抵扣 |
| deductionCurrency | String | 否 | 当switchType = 1时，需要选择抵扣<br>例如 HTX、TRX...... |

**请求参数说明**：假设用户点击余额为零，若switchType=0，调用该接口会有40406的报错

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | integer | 否 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| <data> |  | 否 |  |

## 请求示例
```http
{
  "switchType": 1,
  "deductionCurrency":"TRX"
}
```

## 响应示例
```json
{
  "code": "200",
  "data": {
  },
  "success": true
}
```
