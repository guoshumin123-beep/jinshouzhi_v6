# /v2/account/withdraw/quota (提币额度查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46826-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 此节点用于查询各币种提币额度，限母用户可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | string | 是 | 币种<br>btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys) |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| currency | string | 是 | 币种 |
| <chains> | object | 是 |  |
| chain | string | 是 | 链名称 |
| maxWithdrawAmt | string | 是 | 单次最大提币金额 |
| withdrawQuotaPerDay | string | 是 | 当日提币额度 |
| remainWithdrawQuotaPerDay | string | 是 | 当日提币剩余额度 |
| withdrawQuotaPerYear | string | 是 | 每年最大提款金额 |
| remainWithdrawQuotaPerYear | string | 是 | 年内剩余提款额度 |
| withdrawQuotaTotal | string | 是 | 最大提款总额 |
| remainWithdrawQuotaTotal | string | 是 | 剩余总提款额度 |
| </chains> |  | 否 |  |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v2/account/withdraw/quota?currency=btc"
```
