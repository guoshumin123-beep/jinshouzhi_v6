# /v2/account/withdraw/address (提币地址查询)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec46640-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 接口描述 | 该节点用于查询APIkey可用的提币地址，限母用户可用。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | string | 是 | 币种<br>btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys).假设您需要查询通用地址，则"currency":需要传"t247117"；currency=t397342时可查询到在平台上添加的UID提币地址 |
| chain | string | 否 | 链名称 |
| note | string | 否 | 地址备注 |
| limit | int | 否 | 单页最大返回条目数量<br>[1-500] |
| fromId | long | 否 | 起始编号（提币地址ID，仅在下页查询时有效，详细见备注） |

**请求参数说明**：通用地址的链名chain包括：erc20、trc20、avaxcchain、SOLANA、BRC20、ARBITRUM、OPTIMISM、BTT、bep20、adachain、heco

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| code | int | 是 | 状态码 |
| message | string | 否 | 错误描述（如有） |
| <data> | object | 是 |  |
| currency | string | 是 | 币种 |
| chain | string | 是 | 链名称 |
| note | string | 是 | 地址备注 |
| addressTag | string | 否 | 地址标签，如有 |
| address | string | 是 | 地址 |
| status | string | 是 | 地址状态: normal(常用地址)， white(白名单已生效)，white-delaying(白名单延迟生效中)， processing（待2FA/风控验证） |
| </data> |  | 否 |  |
| nextId | long | 否 | 下页起始编号（提币地址ID，仅在查询结果需要分页返回时，包含此字段，详细见备注） |

## 请求示例
```http
curl"https://api.huobi.pro/v2/account/withdraw/address?currency=usdt&chain=usdterc20&note=HelloWorld"
```

## 响应示例
```json
{
"code":200,
"data":[
{
"currency":"usdt",
"chain":"hrc20usdt",
"note":"tom",
"addressTag":"",
"address":"0x3b994f25c4c25e99d4d26364ffc014cce64600ca"
}
],
"next-id":30137790
}
```
