# /v1/query/deposit-withdraw (充提记录)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec44f99-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 是 |
| 接口权限 | 读取 |
| 限频 | 20次/2s |
| 接口描述 | 此节点用于查询充提记录，母子用户均可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| currency | string | 否 | 币种<br>btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys) |
| type | string | 是 | 充值或提币<br>deposit 或 withdraw,子用户仅可用deposit |
| from | string | 否 | 查询起始 ID |
| size | string | 否 | 查询记录大小<br>[1-50] |
| direct | string | 否 | 返回记录排序方向<br>“prev” （升序）or “next” （降序） |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 是 | 请求返回状态<br>"ok" or "error" |
| error-code | string | 否 | 提币失败错误码，仅type为”withdraw“，且state为”reject“、”wallet-reject“和”failed“时有。 |
| error-msg | string | 否 | 提币失败错误描述，仅type为”withdraw“，且state为”reject“、”wallet-reject“和”failed“时有。 |
| <data> | object | 是 |  |
| id | long | 是 | 充币或者提币订单id，翻页查询时from参数取自此值 |
| type | string | 是 | 类型<br>'deposit', 'withdraw', 子用户仅有deposit |
| currency | string | 是 | 币种 |
| tx-hash | string | 是 | 交易哈希。如果是“快速提币”，则提币不通过区块链，该值为空。 |
| chain | string | 是 | 链名称 |
| amount | float | 是 | 个数 |
| address | string | 是 | 目的地址<br>对于poloniex提币到HTX的记录address返回HTX的UID，格式唯UID:XXXX,比如UID:1234567 |
| address-tag | string | 是 | 地址标签 |
| fee | float | 是 | 手续费 |
| state | string | 是 | 状态<br>虚拟币充值状态[unknown：状态未知，confirming：区块确认中，confirmed：区块已完成，已经上账，可以划转和交易]；虚拟币提币状态[verifying：待验证，failed：验证失败，submitted：已提交，reexamine：审核中，canceled，已撤销，pass：审批通过，reject：审批拒绝，pre-transfer：处理中，wallet-transfer：已汇出，wallet-reject：钱包拒绝，confirmed：区块已确认，confirm-error：区块确认错误，repealed：已撤销]safe：区块已确认，可以提币orphan：区块已被孤立，risk-action-fail：风控验证失败，risk-action-timeout：风控动作超时 |
| created-at | long | 是 | 发起时间 |
| updated-at | long | 是 | 最后更新时间 |
| </data> |  | 否 |  |

## 请求示例
```http
curl"https://api.huobi.pro/v1/query/deposit-withdraw?currency=usdt&type=withdraw"
```
