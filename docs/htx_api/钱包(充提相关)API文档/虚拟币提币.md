# /v1/dw/withdraw/api/create (虚拟币提币)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec42cfd-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 提币 |
| 限频 | 20次/2s |
| 接口描述 | 此节点用于将现货账户的数字币提取到区块链地址（已存在于提币地址列表）而不需要多重（短信、邮件）验证，限母用户可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| address | string | 是 | 提币地址。<br>链上转账时，传入链上地址。<br>内部提币时，可以指定UID、手机号码或邮箱，格式分别为：UID:1234567、 PHONE:0098-1234567、 MAIL:234234@QQ.COM<br>跨所转账时，必须指定poloniex的UUID(必须在官网提前绑定），格式为：POLOUSER:{UUID}，如 POLOUSER:5ac96eed-ba0b-****-****-99e9464a9999<br>仅支持你手动添加到官网的提币地址 |
| amount | string | 是 | 提币数量 |
| currency | string | 是 | 资产类型<br>btc, ltc, bch, eth, etc ...(取值参考GET /v1/common/currencys) |
| fee | float | 否 | 转账手续费。若通过UID、手机号码与邮箱发起的内部提币和跨所转账到poloniex时，则该字段可以传0.字段有值，后端校验数值正确与否；字段无值，后端根据规则自动计算得出<br>>=0，提币前请通过查询手续费接口查询手续费是否过高，免造成损失且提币成功前可通过《取消该提币》接口取消操作 |
| chain | string | 否 | 链上转账时，传入链信息。一币多链的情况下该参数必填，一币一链可不填。<br>内部提币/跨所转账时，必须传入 t397342。<br>取值参考GET /v2/reference/currencies,例如提USDT至OMNI时须设置此参数为"usdt"，提USDT至TRX时须设置此参数为"trc20usdt"，其他币种提币无须设置此参数。 |
| addr-tag | string | 否 | 虚拟币共享地址tag，适用于xrp，xem，bts，steem，eos，xmr。若通过UID提币，则该字段必填，为对方的UID<br>格式多为"123"类的整数，也可以是其他字符串 |
| client-order-id | string | 否 | 客户端提币订单ID（最长32位的字符串）.如字段有值，则后端以此为客户提币订单唯一键值，相同值将被视为幂等提交，而不是创建新提币订单。 |
| exchange-vasp | string | 否 | 交易所id，可以通过 /v1/query/vasp-list 公开接口进行访问.仅适用于TravelRule合规 |
| user-name-vasp | string | 否 | 接收方姓名，支持韩文、英文；姓氏、名字中间用"##"间隔,例如"XING##MING"；如果是英文，所有字母转大写.仅适用于TravelRule合规 |

**请求参数说明**：<br/>client-order-id（客户端提币订单ID）如果不为空，就会做幂等校验，相同client-order-id的提币请求，后发起的会直接返回前面提交成功的提币订单ID

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | long | 否 | 提币 ID |

## 请求示例
```http
# 链上转账
{
  "address":"0xde709f2102306220921060314715629080e2fb77",
  "amount":"0.05",
  "currency":"eth",
  "fee":"0.01",
  "chain":"usdterc20"
}

# 内部转账
{
  "address":"UID:1234567",
  "amount":"0.05",
  "currency":"eth",
  "fee":"0",
  "chain":"t397342"
}

# 跨所转账
{
  "address":"POLOUSER:5ac96eed-ba0b-****-****-99e9464a9999",
  "amount":"0.05",
  "currency":"eth",
  "fee":"0",
  "chain":"t397342"
}
```

## 响应示例
```json
{
  "data":700
}
```
