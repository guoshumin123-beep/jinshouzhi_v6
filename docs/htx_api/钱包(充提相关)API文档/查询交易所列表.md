# /v1/query/vasp-list (查询交易所列表)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=8cb89359-77b5-11ed-9966-195ac811413

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | GET |
| 是否验签 | 否 |
| 接口权限 | 读取 |
| 限频 | 1次/s |
| 接口描述 | 这个接口主要是韩国个人用户，进行提现时输入交易所信息。 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| status | string | 否 | 请求处理结果<br>ok , "error" |
| <data> | object | 是 |  |
| vasp-id | string | 是 | 交易所id |
| vasp-name | string | 是 | 交易所名称 |
| legal-name | string | 是 | 交易所合法名称 |
| <data> |  | 是 |  |
