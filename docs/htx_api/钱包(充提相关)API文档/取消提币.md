# /v1/dw/withdraw-virtual/{withdraw-id}/cancel (取消提币)

> 文档来源：https://www.htx.com/zh-cn/opend/newApiPages/?id=7ec42fa5-7773-11ed-9966-0242ac110003

## 接口信息
| 项目 | 内容 |
|---|---|
| 请求类型 | POST |
| 是否验签 | 是 |
| 接口权限 | 提币 |
| 限频 | 20次/2s |
| 接口描述 | 此节点用于取消已提交的提币请求，限母用户可用 |

## 请求地址
| 环境 | 地址 |
|---|---|
| 线上环境 | `https://api.huobi.pro` |
| 线上环境（aws客户首选） | `https://api-aws.huobi.pro` |

## 请求参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| withdraw-id | long | 是 | 提币 ID，填在 path 中 |

## 响应参数
| 参数 | 数据类型 | 是否必填 | 描述 |
|---|---|---|---|
| data | long | 否 | 提币 ID<br>（取消成功返回提币ID，取消失败返回错误码和原因） |

## 请求示例
```http
{
"withdraw-id":"179211"
}
```

## 响应示例
```json
{
"data":700
}
```
